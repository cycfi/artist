= Rect

== Overview

A `rect` is an axis aligned rectangle held as four `float` edge
coordinates: `left`, `top`, `right` and `bottom`. It is not an origin and
a size. `width()` and `height()` are computed from the edges, and the
constructors that do take an xref:foundation/point.adoc[`extent`] convert
to edges on the way in.

Artist uses screen coordinates, so `y` increases *downward*: `top` is the
smaller `y` and `bottom` the larger. A rectangle whose edges are in that
order is *valid*, which `is_valid` tests. Nothing enforces it. `rect` is a
value type with no invariant, and several operations can hand back a rect
that fails `is_valid`; each is flagged below.

Everything declared in the header is `constexpr` except the nine
functions defined in `rect.cpp`: `intersects`, `union_`, `intersection`,
and the `center` and `align` families. A rect can be built, measured,
moved and inset at compile time, but not intersected or aligned there.

NOTE: `rect.hpp` includes `artist/point.hpp`, so `point`, `extent` and
`axis` come with it.

== Include

```c++
#include <artist/rect.hpp>
```

== Declaration

```c++
struct rect
{
   constexpr         rect();
   constexpr         rect(float left, float top, float right, float bottom);
   constexpr         rect(point origin, float right, float bottom);
   constexpr         rect(point top_left, point bottom_right);
   constexpr         rect(float left, float top, extent size);
   constexpr         rect(point origin, extent size);

   constexpr         rect(rect const&) = default;
   constexpr rect&   operator=(rect const&) = default;

   constexpr bool    operator==(rect const& other) const;
   constexpr bool    operator!=(rect const& other) const;

   constexpr bool    is_empty() const;
   constexpr bool    includes(point p) const;
   constexpr bool    includes(rect const& other) const;

   constexpr float   width() const;
   constexpr void    width(float width_);
   constexpr float   height() const;
   constexpr void    height(float height_);
   constexpr extent  size() const;
   constexpr void    size(extent size_);

   constexpr point   top_left() const;
   constexpr point   bottom_right() const;
   constexpr point   top_right() const;
   constexpr point   bottom_left() const;

   constexpr rect    move(float dx, float dy) const;
   constexpr rect    move_to(float x, float y) const;
   constexpr rect    inset(float x_inset, float y_inset) const;
   constexpr rect    inset(float xy_inset) const;

   float             left;
   float             top;
   float             right;
   float             bottom;
};

// Free Functions

rect                 intersection(rect const& a, rect const& b);

constexpr void       clear(rect& r);
rect                 center(rect const& r, rect const& encl);
rect                 center_h(rect const& r, rect const& encl);
rect                 center_v(rect const& r, rect const& encl);
rect                 align(rect const& r, rect const& encl, float x_align, float y_align);
rect                 align_h(rect const& r, rect const& encl, float x_align);
rect                 align_v(rect const& r, rect const& encl, float y_align);

constexpr float      axis_extent(rect const& r, axis a);
```

== Expressions

=== Notation

`r`, `a`, `b`     :: Objects of type `rect`.
`encl`            :: Object of type `rect` that encloses `r`.
`tl`, `br`        :: Objects of type `point` for the top left and bottom
                     right corners.
`p`               :: Object of type `point` to test.
`e`               :: Object of type `extent` for a size.
`ax`              :: Object of type `axis`.
`left`, `top`, `right`, `bottom` :: Floating point values for the edges.
`x`, `y`          :: Floating point values for the new top left corner.
`w`, `h`          :: Floating point values for the width and height.
`dx`, `dy`        :: Floating point values for an offset.
`d`               :: Floating point value for an inset distance on all
                     four sides.
`ix`, `iy`        :: Floating point values for the horizontal and vertical
                     inset distances.
`fx`, `fy`        :: Floating point values for the horizontal and vertical
                     alignment fractions.
`amin`, `amax`    :: Floating point values for the edges along `ax`.
`omin`, `omax`    :: Floating point values for the edges along
                     `other(ax)`.

=== Constructors and Assignment

[cols="1,1"]
|===
| Expression                        | Semantics

| `rect()`                          | Construct an empty `rect` at the
                                      origin, `{0, 0, 0, 0}`.
| `rect(left, top, right, bottom)`  | Construct a `rect` given `left`,
                                      `top`, `right` and `bottom` (edges).
| `rect(tl, right, bottom)`         | Construct a `rect` given `tl` (top
                                      left corner) and the *absolute*
                                      `right` and `bottom` edges.
| `rect(tl, br)`                    | Construct a `rect` given `tl` and
                                      `br` (opposite corners).
| `rect(left, top, e)`              | Construct a `rect` given `left`,
                                      `top` (top left edges) and `e`
                                      (size). The right edge is
                                      `left + e.x`, the bottom `top + e.y`.
| `rect(tl, e)`                     | Construct a `rect` given `tl` (top
                                      left corner) and `e` (size).
| `rect(r)`                         | Copy construct from `rect r`.
| `a = b`                           | Assign `b` to `a`.
|===

NOTE: C++ brace initialization may also be used. `rect` is not an
aggregate, so braces call the constructors above. As with
xref:foundation/point.adoc[`point`], brace initialization forbids
narrowing, so `rect{n, top, right, bottom}` with an `int` `n` does not
compile; write `rect(n, top, right, bottom)` with parentheses.

WARNING: `rect(tl, right, bottom)` takes *absolute* edges, while
`rect(tl, e)` takes a size. The two have the same shape at the call
site and different meanings: `rect{point(10, 10), 100, 100}` is 90 by 90,
`rect{point(10, 10), extent(100, 100)}` is 100 by 100. Reach for the
`extent` form whenever the second argument is a size.

=== Access

[cols="1,1,1"]
|===
| Expression  | Semantics                                    | Return Type

| `r.left`    | Access the left edge, the smaller `x`.       | `float`
| `r.top`     | Access the top edge, the smaller `y`.        | `float`
| `r.right`   | Access the right edge, the larger `x`.       | `float`
| `r.bottom`  | Access the bottom edge, the larger `y`.      | `float`
|===

=== Accessors

[cols="1,1,1"]
|===
| Expression          | Semantics                            | Return Type

| `r.width()`         | Get the width, `right - left`,
                        negative when `right < left`.        | `float`
| `r.height()`        | Get the height, `bottom - top`,
                        negative when `bottom < top`.        | `float`
| `r.size()`          | Get the size, `{width(), height()}`. | `extent`
| `r.top_left()`      | Get the top left corner,
                        `{left, top}`.                       | `point`
| `r.top_right()`     | Get the top right corner,
                        `{right, top}`.                      | `point`
| `r.bottom_left()`   | Get the bottom left corner,
                        `{left, bottom}`.                    | `point`
| `r.bottom_right()`  | Get the bottom right corner,
                        `{right, bottom}`.                   | `point`
| `r.is_empty()`      | Test whether *either* dimension is
                        zero, `left == right` or
                        `top == bottom`.                     | `bool`
| `r.includes(p)`     | Test whether `p` lies within `r`,
                        borders included.                    | `bool`
| `a.includes(b)`     | Test whether all four edges of `b`
                        lie within `a`, borders included, so
                        a rect includes itself.              | `bool`
|===

NOTE: One zero dimension is enough for `is_empty()`:
`rect(0, 0, 100, 0)` is empty, and its `size()` is `{100, 0}`.

=== Mutators

[cols="1,1,1"]
|===
| Expression     | Semantics                                 | Return Type

| `r.width(w)`   | Set the width, moving the *right* edge to
                   `left + w`.                               | `void`
| `r.height(h)`  | Set the height, moving the *bottom* edge
                   to `top + h`.                             | `void`
| `r.size(e)`    | Set the width and height from `e`, moving
                   the right and bottom edges.               | `void`
|===

=== Operation

[cols="1,1,1"]
|===
| Expression           | Semantics                           | Return Type

| `r.move(dx, dy)`     | Get a copy of `r` moved by `dx` and
                         `dy`, the size unchanged.           | `rect`
| `r.move_to(x, y)`    | Get a copy of `r` with its *top left
                         corner* at `{x, y}`, the size
                         unchanged.                          | `rect`
| `r.inset(ix, iy)`    | Get a copy of `r` shrunk by `ix` on
                         the left and right and by `iy` on
                         the top and bottom.                 | `rect`
| `r.inset(d)`         | Get a copy of `r` shrunk by `d` on
                         all four sides.                     | `rect`
|===

WARNING: A negative inset grows the rect, and `inset` clamps hard. If the
inset would leave an invalid rect, the result is `{0, 0, 0, 0}`: `inset`
calls `clear` on it, which discards the position as well as the size.
Over-insetting on one axis alone is enough, so
`rect(0, 0, 100, 60).inset(40)` is `{0, 0, 0, 0}` rather than a rect
20 wide. Check `width()` and `height()` against the inset first if the
distance is not known to be small. This is the opposite of
xref:foundation/circle.adoc[`circle::inset`], which does not clamp at all
and hands back a negative radius.

NOTE: `move_to` places the *top left corner*, where
xref:foundation/circle.adoc[`circle::move_to`] places the centre.

=== Comparison

[cols="1,1,1"]
|===
| Expression   | Semantics                                   | Return Type

| `a == b`     | Equality.                                   | `bool`
| `a != b`     | Non-Equality.                               | `bool`
|===

NOTE: The comparison of the four edges is exact, so two rects differing
only by rounding are not equal.

=== Functions

[cols="1,1,1"]
|===
| Expression                  | Semantics                    | Return Type

| `is_valid(r)`               | Test whether `+left <= right+`
                                and `+top <= bottom+`. An
                                empty rect is valid.         | `bool`
| `is_same_size(a, b)`        | Test whether `a` and `b` have
                                the same width and height,
                                wherever they are.           | `bool`
| `intersects(a, b)`          | Test whether `a` and `b`
                                overlap.                     | `bool`
| `center_point(r)`           | Get the centre of `r`,
                                `{left + width()/2,
                                top + height()/2}`.          | `point`
| `area(r)`                   | Get the area,
                                `width() * height()`,
                                negative when exactly one
                                dimension is inverted.       | `float`
| `union_(a, b)`              | Get the smallest rect covering
                                `a` and `b`: the min of the
                                left and top edges, the max
                                of the right and bottom.     | `rect`
| `intersection(a, b)`        | Get the overlap of `a` and
                                `b`: the max of the left and
                                top edges, the min of the
                                right and bottom.            | `rect`
| `clear(r)`                  | Set all four edges of `r` to
                                zero, an empty rect at the
                                origin.                      | `void`
| `center(r, encl)`           | Get a copy of `r` centred in
                                `encl`, the same as
                                `align(r, encl, 0.5, 0.5)`.  | `rect`
| `center_h(r, encl)`         | Get a copy of `r` centred
                                horizontally in `encl`, with
                                `r.top` kept.                | `rect`
| `center_v(r, encl)`         | Get a copy of `r` centred
                                vertically in `encl`, with
                                `r.left` kept.               | `rect`
| `align(r, encl, fx, fy)`    | Get a copy of `r` placed in
                                `encl` at the fractions `fx`
                                and `fy`: `0` against the
                                left or top of `encl`, `1`
                                against the right or bottom,
                                `0.5` centred.               | `rect`
| `align_h(r, encl, fx)`      | Get a copy of `r` placed
                                horizontally in `encl` at the
                                fraction `fx`, with `r.top`
                                kept.                        | `rect`
| `align_v(r, encl, fy)`      | Get a copy of `r` placed
                                vertically in `encl` at the
                                fraction `fy`, with `r.left`
                                kept.                        | `rect`
| `axis_extent(r, ax)`        | Get the size of `r` along
                                `ax`: `width()` for
                                `axis::x`, `height()` for
                                `axis::y`.                   | `float`
| `axis_min(r, ax)`           | Access the lower edge along
                                `ax`: `left` for `axis::x`,
                                `top` for `axis::y`.         | `float&`, or
                                                               `float` if `r`
                                                               is `const`
| `axis_max(r, ax)`           | Access the upper edge along
                                `ax`: `right` for `axis::x`,
                                `bottom` for `axis::y`.      | `float&`, or
                                                               `float` if `r`
                                                               is `const`
|===

NOTE: `intersects` is *strict* where `includes` is inclusive. Two rects
that share an edge do not intersect, yet each includes the points along
that edge. `rect(0, 0, 10, 10)` and `rect(10, 0, 20, 10)` give
`intersects` `false` and both give `includes(point(10, 5))` `true`.

WARNING: `intersection` does not test for overlap first. On rects that
do not intersect it returns an inverted rect, for example
`{100, 100, 10, 10}`. Guard it with `intersects`, or test the result with
`is_valid`.

NOTE: `union_` takes no notice of emptiness, so `union_(rect{}, r)` always
stretches the result back to the origin. Skip the empty operand rather
than folding it in.

The placement functions, `center` to `align_v`, keep the size of `r` and
never modify `encl`. The fractions are not clamped and nothing requires
`r` to fit inside `encl`. A fraction outside `0` to `1` places `r` outside
`encl`, and if `r` is the larger of the two the alignment runs the other
way, which is occasionally what you want.

The `axis` functions pick the edge or dimension that matches an
xref:foundation/point.adoc[`axis`], so a routine can be written once and
run in either direction. They are the `rect` counterpart of
`point::operator[]`.

NOTE: The four `axis` helpers are defined in `rect.hpp` but do not appear
in its Free Functions declaration block, so they are easy to miss when
skimming the header.

=== Factory

[cols="1,1,1"]
|===
| Expression                          | Semantics            | Return Type

| `make_rect(ax, amin, omin,

                                        `amin`, `amax` (the
                                        edges along `ax`)
                                        and `omin`, `omax`

=== Example

Lay a fixed size badge into the top right of a card, with a margin, and
paint only the part of it that is on screen.

```c++
#include <artist/rect.hpp>
#include <artist/canvas.hpp>             // For canvas
...
using namespace cycfi::artist;
extern canvas cnv;                       // the canvas to draw on
...
   auto bounds = rect{20, 20, 320, 140};
   auto clip = rect{0, 0, 282, 160};

   // The card.
   cnv.fill_style(colors::gray[92]);
   cnv.fill_round_rect(bounds, 6);
   cnv.stroke_style(colors::gray[70]);
   cnv.line_width(1);
   cnv.stroke_round_rect(bounds, 6);

   // A fixed size badge, hard right and hard top inside the margin.
   auto slot = rect{0, 0, extent{64, 24}};                    <1>
   auto badge = align(slot, bounds.inset(10), 1.0f, 0.0f);    <2>

   // Only the part of it that is on screen gets painted.
   if (intersects(badge, clip))                               <3>
   {
      auto visible = intersection(badge, clip);               <4>
      cnv.fill_style(colors::medium_violet_red);
      cnv.fill_round_rect(visible, 4);
   }
```

<1> Construct a 64 by 24 slot from a size.
<2> Inset the card by 10 for the margin, and align the slot in it, hard
    right (1.0) and hard top (0.0), without any arithmetic on the edges.
<3> Test whether any of the badge is on screen.
<4> Cut the badge back to the part inside `clip`.

Write a layout step once for either axis: split a rect into two at a
fraction along `ax`.

```c++
#include <artist/rect.hpp>
#include <utility>                       // For std::make_pair
...
using namespace cycfi::artist;
...
constexpr auto split(rect r, axis ax, float frac)
{
   auto at = axis_min(r, ax) + (axis_extent(r, ax) * frac);   <1>
   auto first = r, second = r;
   axis_max(first, ax) = at;                                  <2>
   axis_min(second, ax) = at;
   return std::make_pair(first, second);
}
```

<1> Find the split point along `ax`, from the lower edge and the size
    along `ax`.
<2> Move the upper edge of the first half and the lower edge of the
    second to the split point, through the references `axis_max` and
    `axis_min` return.
