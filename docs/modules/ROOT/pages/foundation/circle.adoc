= Circle

== Overview

A `circle` is a centre and a radius: `cx`, `cy` and `radius`, all `float`.
It is a value type with no invariant, so nothing stops a negative radius;
see the warning under <<Operation>>.

Only the constructors are `constexpr`. The accessors and the operations
are plain `inline`, so a `circle` can be built at compile time but not
queried or transformed there. This differs from
xref:foundation/rect.adoc[Rect], where nearly everything is `constexpr`.

NOTE: `circle.hpp` includes `artist/rect.hpp`, which in turn includes
`artist/point.hpp`, so `rect`, `point` and `extent` come with it.

== Include

```c++
#include <artist/circle.hpp>
```

== Declaration

```c++
struct circle
{
   constexpr   circle();
   constexpr   circle(float cx, float cy, float radius);
   constexpr   circle(point c, float radius);
   constexpr   circle(rect const& r);
               circle(circle const&) = default;
   circle&     operator=(circle const&) = default;

   rect        bounds() const;
   bool        operator==(circle const& other) const;
   bool        operator!=(circle const& other) const;

   point       center() const;
   circle      inset(float x) const;
   circle      move(float dx, float dy) const;
   circle      move_to(float x, float y) const;

   float       cx;
   float       cy;
   float       radius;
};
```

== Expressions

=== Notation

`c`, `a`, `b`     :: Objects of type `circle`.
`p`               :: Object of type `point`.
`r`               :: Object of type `rect`.
`cx`, `cy`        :: Floating point values for the centre coordinates.
`radius`          :: Floating point value for the radius.
`x`, `y`          :: Floating point values for the new centre.
`dx`, `dy`        :: Floating point values for an offset.
`d`               :: Floating point value for an inset distance.

=== Constructors and Assignment

[cols="1,1"]
|===
| Expression                  | Semantics

| `circle()`                  | Construct a `circle` at the origin with a
                                radius of zero.
| `circle(cx, cy, radius)`    | Construct a `circle` given `cx`, `cy`
                                (centre coordinates) and `radius`.
| `circle(p, radius)`         | Construct a `circle` given `p` (centre) and
                                `radius`.
| `circle(r)`                 | Construct a `circle` centred on `r`, with the
                                smaller side of `r` as its radius.
| `circle(c)`                 | Copy construct from `circle c`.
| `a = b`                     | Assign `b` to `a`.
|===

NOTE: C++ brace initialization may also be used. `circle` is not an
aggregate, so braces call the constructors above.

WARNING: `circle(r)` takes the smaller side of `r` as the *radius*, not as
the diameter, so the circle it builds is twice the size that fits in `r`.
`circle(rect{0, 0, 100, 60})` is centred at `{50, 30}` with a radius of 60,
and its `bounds()` is 120 by 120 around a rect that is 100 by 60. Pass
`std::min(r.width(), r.height()) / 2` as the radius for the inscribed
circle.

=== Access

[cols="1,1,1"]
|===
| Expression  | Semantics                                    | Return Type

| `c.cx`      | Access the x coordinate of the centre.       | `float`
| `c.cy`      | Access the y coordinate of the centre.       | `float`
| `c.radius`  | Access the radius.                           | `float`
|===

=== Accessors

[cols="1,1,1"]
|===
| Expression    | Semantics                                  | Return Type

| `c.center()`  | Get the centre, `{cx, cy}`.                | `point`
| `c.bounds()`  | Get the axis aligned bounding box,
                  `{cx-radius, cy-radius, cx+radius,
                  cy+radius}`.                               | `rect`
|===

=== Operation

[cols="1,1,1"]
|===
| Expression         | Semantics                             | Return Type

| `c.inset(d)`       | Get a copy of `c` with the radius
                       reduced by `d`, the centre unchanged. | `circle`
| `c.move(dx, dy)`   | Get a copy of `c` with the centre
                       moved by `dx` and `dy`.               | `circle`
| `c.move_to(x, y)`  | Get a copy of `c` with the centre
                       placed at `{x, y}`.                   | `circle`
|===

WARNING: `inset` does not clamp, and a negative `d` grows the circle.
Insetting further than the radius gives a negative radius, and `bounds()`
on that circle returns a rect for which `is_valid` is `false`. Check the
radius yourself if the inset can exceed it.

NOTE: `move_to` places the *centre*.
xref:foundation/rect.adoc[`rect::move_to`] places the top left corner.

=== Comparison

[cols="1,1,1"]
|===
| Expression   | Semantics                                   | Return Type

| `a == b`     | Equality.                                   | `bool`
| `a != b`     | Non-Equality.                               | `bool`
|===

NOTE: The comparison of `cx`, `cy` and `radius` is exact, so two circles
differing only by rounding are not equal.

=== Example

Draw a dial face: a filled circle with a ring inside it.

```c++
#include <artist/circle.hpp>
#include <artist/canvas.hpp>             // For canvas
...
using namespace cycfi::artist;
extern canvas cnv;                       // the canvas to draw on
...
   auto bounds = rect{0, 0, 200, 140};
   auto dial = circle{center_point(bounds), 40};         <1>

   cnv.add_circle(dial);                                 <2>
   cnv.fill_style(colors::gray[20]);
   cnv.fill();

   cnv.add_circle(dial.inset(6));                        <3>
   cnv.stroke_style(colors::light_steel_blue);
   cnv.line_width(2);
   cnv.stroke();
```

<1> Construct a circle of radius 40 at the centre of `bounds`.
<2> Add the circle to the current path and fill it.
<3> Inset the circle by 6 and stroke it. `inset` shrinks about the same
    centre, so the ring stays concentric with the face without any
    arithmetic on `cx` and `cy`.
