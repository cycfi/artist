= Affine Transform

== Overview

The `affine_transform` is the matrix behind the canvas
xref:canvas/transforms.adoc[Transforms]. It maps a point in the coordinates
you draw in, called user space, to a point in the coordinates of the
surface, called device space. It is what `canvas::transform()` returns and
what `canvas::transform(mat)` takes.

image::foundation/affine_transform.svg[alt="Affine transform matrix", width=560px, align=center, title="The six stored members and the mapping they define. The third column is fixed and is not stored.", link={imagesdir}/foundation/affine_transform.svg]

The `a`, `b`, `c` and `d` members carry the linear part, which is scale,
rotation and skew. The `tx` and `ty` members carry the translation. A
default constructed `affine_transform` is the identity.

The type is a plain aggregate of six `double` members, so it is cheap to
copy and usable in constant expressions. Everything except `rotate`,
`skew`, `make_rotation` and `make_skew`, which need `std::sin`, `std::cos`
and `std::tan`, is `constexpr`.

NOTE: Artist's y axis grows downward, so a positive rotation, which takes
the positive x axis toward the positive y axis, appears clockwise on
screen.

NOTE: See xref:foundation.adoc[Foundation] for an overview of the foundation classes.

== Include

```c++
#include <artist/affine_transform.hpp>
```

== Declaration

```c++
struct affine_transform
{
   constexpr bool                   is_identity() const;
   constexpr affine_transform       translate(double tx, double ty) const;
   constexpr affine_transform       scale(double sx, double sy) const;
   constexpr affine_transform       scale(double sc) const;
   inline affine_transform          rotate(double rad) const;
   inline affine_transform          skew(double sx, double sy) const;
   constexpr affine_transform       invert() const;

   constexpr point                  apply(point p) const;
   constexpr point                  apply(float x, float y) const;

                                    template <std::size_t N>
   constexpr void                   apply(point p[N]) const;
   constexpr void                   apply(point p[], std::size_t n) const;

   double a    = 1.0;
   double b    = 0.0;
   double c    = 0.0;
   double d    = 1.0;
   double tx   = 0.0;
   double ty   = 0.0;
};

constexpr affine_transform affine_identity;

constexpr bool             operator==(affine_transform const& lhs, affine_transform const& rhs);
constexpr bool             operator!=(affine_transform const& lhs, affine_transform const& rhs);
constexpr affine_transform operator*(affine_transform t1, affine_transform t2);

// Factory functions
constexpr affine_transform make_translation(double tx, double ty);
constexpr affine_transform make_scale(double sx, double sy);
constexpr affine_transform make_scale(double sc);
inline affine_transform    make_rotation(double rad);
inline affine_transform    make_skew(double sx, double sy);
```

== Expressions

=== Notation

`t`, `t1`, `t2`   :: Objects of type `affine_transform`.
`a`, `b`, `c`, `d`, `tx`, `ty` :: Floating point values for the six
                     members.
`p`               :: Object of type `point`.
`x`, `y`          :: Floating point values for the coordinates of a
                     point.
`sx`, `sy`        :: Floating point values for the scale factors.
`sc`              :: Floating point value for a uniform scale factor.
`kx`, `ky`        :: Floating point values for the skew angles, in
                     radians.
`rad`             :: Floating point value for an angle, in radians.
`pts`             :: Array of `point`.
`n`               :: Object of type `std::size_t` for a count.
`N`               :: Compile time `std::size_t` for a count.

=== Constructors and Assignment

[cols="1,1"]
|===
| Expression                        | Semantics

| `affine_transform()`              | Construct the identity transform,
                                      `{1, 0, 0, 1, 0, 0}`.
| `affine_transform{a, b, c, d,
    tx, ty}`                        | Construct an `affine_transform`
                                      given the six members, in
                                      declaration order.
| `affine_transform(t)`             | Copy construct from
                                      `affine_transform t`.
| `t1 = t2`                         | Assign `t2` to `t1`.
|===

NOTE: `affine_transform` is an aggregate with no user declared
constructors. The members may be given in part and the rest take their
default values, so `affine_transform{2.0}` is a scale of 2 in x only.

=== Access

[cols="1,1,1"]
|===
| Expression   | Semantics                                   | Return Type

| `t.a`        | Access the factor of `x` in the mapped x.   | `double`
| `t.b`        | Access the factor of `x` in the mapped y.   | `double`
| `t.c`        | Access the factor of `y` in the mapped x.   | `double`
| `t.d`        | Access the factor of `y` in the mapped y.   | `double`
| `t.tx`       | Access the translation in x.                | `double`
| `t.ty`       | Access the translation in y.                | `double`
|===

A point `{x, y}` maps to `{a * x + c * y + tx, b * x + d * y + ty}`.

=== Accessors

[cols="1,1,1"]
|===
| Expression         | Semantics                             | Return Type

| `t.is_identity()`  | Test whether `t` equals
                       `affine_identity`.                    | `bool`
|===

=== Operation

[cols="1,1,1"]
|===
| Expression             | Semantics                     | Return Type

| `t.translate(tx, ty)`  | Get `t` composed with a
                           translation by `tx` and `ty`. | `affine_transform`
| `t.scale(sx, sy)`      | Get `t` composed with a scale
                           by `sx` and `sy`.             | `affine_transform`
| `t.scale(sc)`          | Get `t` composed with a
                           uniform scale by `sc`.        | `affine_transform`
| `t.rotate(rad)`        | Get `t` composed with a
                           rotation by `rad`.            | `affine_transform`
| `t.skew(kx, ky)`       | Get `t` composed with a skew
                           by `kx` and `ky`.             | `affine_transform`
| `t.invert()`           | Get the inverse of `t`, which
                           maps a device space point
                           back to the user space point
                           it came from.                 | `affine_transform`
| `t.apply(p)`           | Map `p` through `t`.          | `point`
| `t.apply(x, y)`        | Map the point `{x, y}`
                           through `t`.                  | `point`
| `t.apply<N>(pts)`      | Map the first `N` points of
                           `pts` in place.               | `void`
| `t.apply(pts, n)`      | Map the first `n` points of
                           `pts` in place.               | `void`
|===

WARNING: If the determinant, `a * d - c * b`, is zero, `t` is not
invertible and `invert` returns `t` unchanged. No error is reported, so
check the determinant yourself if a degenerate transform is possible.

NOTE: `N` cannot be deduced from an array parameter, so `t.apply<N>(pts)`
must be given the count as an explicit template argument. The arithmetic
is done in `double` and narrowed to the `float` members of `point`.

=== Comparison

[cols="1,1,1"]
|===
| Expression         | Semantics                             | Return Type

| `t1 == t2`         | Equality.                             | `bool`
| `t1 != t2`         | Non-Equality.                         | `bool`
|===

NOTE: The comparison of the six members is exact, so two transforms
differing only by rounding are not equal.

=== Arithmetic

[cols="1,1,1"]
|===
| Expression         | Semantics                     | Return Type

| `t1 * t2`          | Get the transform that applies
                       `t2` first and then `t1`, so
                       that `(t1 * t2).apply(p)`
                       equals
                       `t1.apply(t2.apply(p))`.      | `affine_transform`
|===

The composing members are defined as `t * make_translation(tx, ty)` and so
on, which means the new operation applies within the space `t` already
establishes. This is the same rule the canvas calls follow: scaling by 2
and then translating by 10 moves by 20 device units. Composition is not
commutative, so `t1 * t2` and `t2 * t1` differ in general.

=== Constants

[cols="1,1,1"]
|===
| Expression          | Semantics                       | Return Type

| `affine_identity`   | Get the identity transform.     | `affine_transform`
|===

=== Factory

[cols="1,1,1"]
|===
| Expression                 | Semantics                  | Return Type

| `make_translation(tx, ty)` | Make a translation by `tx`
                               and `ty`,
                               `{1, 0, 0, 1, tx, ty}`.    | `affine_transform`
| `make_scale(sx, sy)`       | Make a scale about the
                               origin,
                               `{sx, 0, 0, sy, 0, 0}`.    | `affine_transform`
| `make_scale(sc)`           | Make a uniform scale about
                               the origin,
                               `{sc, 0, 0, sc, 0, 0}`.    | `affine_transform`
| `make_rotation(rad)`       | Make a rotation about the
                               origin, `{cos(rad),
                               sin(rad), -sin(rad),
                               cos(rad), 0, 0}`.          | `affine_transform`
| `make_skew(kx, ky)`        | Make a skew,
                               `{1, tan(kx), tan(ky), 1,
                               0, 0}`: `kx` is the angle
                               by which y shears with x,
                               and `ky` the angle by
                               which x shears with y.     | `affine_transform`
|===

Scale and rotation are about the origin, not the centre of what you are
drawing. Translate first to work about some other point.

=== Example

Rotate a point by 45 degrees about the point `{cx, cy}`.

```c++
#include <artist/affine_transform.hpp>
...
using namespace cycfi::artist;
float cx, cy;                            // the point to rotate about
float x, y;                              // the point to map
...
   auto t = affine_identity
      .translate(cx, cy)                                 <1>
      .rotate(M_PI / 4)                                  <2>
      .translate(-cx, -cy)                               <3>
      ;

   auto p = t.apply(point{x, y});                        <4>
```

<1> Start from the identity and translate by `cx` and `cy`, the last step
    applied to the point.
<2> Rotate by 45 degrees.
<3> Translate by `-cx` and `-cy`, the first step applied to the point,
    which brings `{cx, cy}` to the origin.
<4> Map the point `{x, y}` through `t`.
