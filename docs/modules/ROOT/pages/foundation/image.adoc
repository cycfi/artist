= Image

== Overview

An `image` is a bitmap the canvas can paint. It is what the
xref:canvas/images.adoc[Images] calls take. There are three ways to get
one: load it from a file, build it from a buffer of pixels with
`make_image`, or create a blank one of a given size and draw into it
through an `offscreen_image`.

A file name that is not absolute is looked up through the
xref:foundation/resources.adoc[Resources] search list. PNG is read on every
backend; which other formats load depends on the backend's decoder.

An `image` owns backend storage, so it can be moved but not copied. Share
one through `image_ptr`, which is a `std::shared_ptr<image>`.

To draw into an image, construct an `offscreen_image` on it, build a
`canvas` on the offscreen image's `context()`, and draw. The drawing is in
the image once the `offscreen_image` has been destroyed, and not reliably
before, so give it a scope of its own and keep the canvas inside that
scope. The <<Example>> shows the pattern.

NOTE: Drawing an image, and drawing into one, behave alike on all three
backends. The pixel level API does not: what `pixels()` points at, how
`make_image` reads its buffer, and how a failure is reported all vary
between Quartz 2D, Skia and Cairo. The differences are set out under
<<Backend Differences>>.

== Declaration

```c++
   enum class pixel_format
   {
      invalid = -1,
      gray8,
      rgb16,
      rgb32,
      rgba32,
   };
```

```c++
   class image
   {
   public:

      explicit          image(float sizex, float sizey);
      explicit          image(extent size);
      explicit          image(fs::path const& path_);

                        image(image const& rhs) = delete;
                        image(image&& rhs) noexcept;
                        ~image();

      image&            operator=(image const& rhs) = delete;
      image&            operator=(image&& rhs) noexcept;

      image_impl_ptr    impl() const;
      extent            size() const;
      void              save_png(std::string_view path) const;

      uint32_t*         pixels();
      uint32_t const*   pixels() const;
      extent            bitmap_size() const;
   };

   using image_ptr = std::shared_ptr<image>;
```

```c++
   class offscreen_image
   {
   public:

      explicit          offscreen_image(image& img);
                        offscreen_image(offscreen_image const&) = delete;
                        ~offscreen_image();

      offscreen_image&  operator=(offscreen_image const& rhs) = delete;

      canvas_impl*      context() const;
   };
```

```c++
   // Free functions
   template <pixel_format fmt>      // gray8
   image make_image(std::uint8_t const* data, extent size);

   image make_image(std::uint16_t const* data, extent size);

   template <pixel_format fmt>      // rgb32 or rgba32

```

== Expressions

=== Notation

`img`, `img2`  :: Objects of type `image`.
`sx`, `sy`     :: `float` width and height.
`sz`           :: Object of type `extent`, a width and height.
`p`            :: Object of type `fs::path`, an image file name, relative
                  or absolute.
`str`          :: A `std::string_view`, a file name.
`d8`           :: A `std::uint8_t const*`, a buffer of pixels.
`d16`          :: A `std::uint16_t const*`, a buffer of pixels.
`d32`          :: A `std::uint32_t const*`, a buffer of pixels.
`off`          :: Object of type `offscreen_image`.

=== Constructors and Assignment

[cols="1,1"]
|===
| Expression                  | Semantics

| `image(sx, sy)`             | Construct a blank, fully transparent image
                                `sx` by `sy` in size.
| `image(sz)`                 | As above, `sz` in size.
| `image(p)`                  | Load the image file `p`. Throws
                                `std::runtime_error` if the file is
                                missing or cannot be decoded, except on
                                Quartz 2D.
| `image(std::move(img))`     | Move construct from `img`, which is left
                                holding nothing.
| `img = std::move(img2)`     | Move assign `img2` to `img`. `img2` is
                                left holding nothing.
|===

All three constructors are `explicit`, so an `extent` or a path does not
convert to an `image` implicitly.

WARNING: A moved from `image` holds nothing. Destroy it or assign to it;
calling any other member on it is undefined behaviour.

=== Construction from Pixels

`make_image` builds an image from a buffer of `sz.x` by `sz.y` pixels,
stored row by row from the top with no padding between rows. The format is
a template argument, and each overload accepts only the formats that match
its pointer type, so `pixel_format::invalid` is rejected at compile time.

[cols="1,1,1"]
|===
| Expression                                    | Semantics                         | Return Type

| `make_image<pixel_format::gray8>(d8, sz)`     | Eight bit gray levels, one byte
                                                  per pixel. Opaque.                | `image`
| `make_image<pixel_format::rgb16>(d16, sz)`    | Sixteen bit 5-6-5 pixels, red in
                                                  the top five bits. Opaque.        | `image`
| `make_image<pixel_format::rgb32>(d32, sz)`    | Four bytes per pixel: R, G and B
                                                  in memory order, then a byte
                                                  that is ignored. Opaque.          | `image`
| `make_image<pixel_format::rgba32>(d32, sz)`   | Four bytes per pixel: R, G, B and
                                                  A in memory order.                | `image`
|===

CAUTION: Only opaque `gray8` and `rgba32` pixels are read the same way by
every backend. Whether the buffer is copied, how `rgba32` alpha is read,
and whether `rgb16` and `rgb32` work at all depend on the backend. Keeping
the buffer alive for as long as the image is safe on all three.

=== Accessors

[cols="1,1,1"]
|===
| Expression          | Semantics                              | Return Type

| `img.size()`        | The size of the image. `draw` places
                        the image at this size in user space,
                        and the `src` rectangle `draw` takes is
                        in these units.                        | `extent`
| `img.bitmap_size()` | The width and height, in pixels, of
                        the buffer `pixels()` points at, or
                        `{0, 0}` when there is none.           | `extent`
| `img.impl()`        | The backend's image handle, for code
                        that talks to the backend directly.    | `image_impl_ptr`
|===

=== Pixel Access

[cols="1,1,1"]
|===
| Expression      | Semantics                                  | Return Type

| `img.pixels()`  | The first pixel of the bitmap, or
                    `nullptr` if the image has none. Rows run
                    from the top, `bitmap_size().x` pixels to
                    a row, with no padding.                    | `uint32_t*`, or
                                                                 `uint32_t const*`
                                                                 if `img` is
                                                                 `const`
|===

CAUTION: What the pixels are depends on the backend and on where the image
came from. On Quartz 2D, an image drawn through an `offscreen_image` does
not hold 32 bit pixels at all. To inspect pixels on every backend, save
the image with `save_png` and load the file back: a loaded PNG always gives
32 bit pixels, though not in the same channel order everywhere.

NOTE: Treat the buffer as read only. There is no call to tell the backend
that the pixels have changed, and Cairo needs one before it uses the image
again.

=== Output

[cols="1,1,1"]
|===
| Expression            | Semantics                            | Return Type

| `img.save_png(str)`   | Write the image to the file `str` as
                          a PNG, `size().x` by `size().y`
                          pixels. `str` is used as given; it is
                          not looked up through the resource
                          search list.                         | `void`
|===

Only Cairo reports a failure to write the file.

=== Offscreen Construction

[cols="1,1"]
|===
| Expression               | Semantics

| `offscreen_image(img)`   | Begin drawing into `img`, which must
                             outlive the `offscreen_image`.
|===

An `offscreen_image` is neither copyable nor movable. Its destructor ends
the drawing: everything drawn through its context is in the image once it
has been destroyed.

=== Offscreen Context

[cols="1,1,1"]
|===
| Expression        | Semantics                              | Return Type

| `off.context()`   | The backend drawing context, from
                      which a `canvas` is built:
                      `canvas(off.context())`. Valid only
                      while `off` lives, so the canvas must
                      not outlive it.                        | `canvas_impl*`
|===

== Backend Differences

The table records what each backend does today where they part ways.

[cols="2,1,1,1"]
|===
| Behaviour                          | Quartz 2D                 | Skia                      | Cairo

| `image(p)` when `p` is missing
  or cannot be decoded               | Returns an empty image,
                                       `size()` is `{0, 0}`      | Throws
                                                                   `std::runtime_error`      | Throws
                                                                                               `std::runtime_error`
| `save_png` cannot write the file   | Not reported              | Not reported              | Throws
                                                                                               `std::runtime_error`
| A blank image before any drawing   | No bitmap, `pixels()` is
                                       `nullptr`                 | No bitmap, `pixels()` is
                                                                   `nullptr`                 | A transparent bitmap
| `offscreen_image` on an image
  that already holds something       | Draws over it             | Starts from transparent
                                                                   and replaces it           | Draws over it
| The `make_image` buffer            | Read in place, so it must
                                       outlive the image         | Copied                    | Copied
| `rgba32` alpha                     | Read as premultiplied     | Declared opaque, so a
                                                                   pixel with alpha below
                                                                   255 draws undefined       | Read as straight
| `rgb16`                            | Not read as 5-6-5         | Supported                 | Supported
| `rgb32`                            | Draws nothing             | Supported                 | Supported
| `pixels()` of a loaded PNG         | R, G, B, A bytes,
                                       straight alpha            | B, G, R, A bytes,
                                                                   straight alpha            | B, G, R, A bytes,
                                                                                               premultiplied
| `pixels()` after drawing through
  an `offscreen_image`               | Not 32 bit pixels.
                                       `bitmap_size()` is
                                       `{0, 0}` until `pixels()`
                                       is first called, then
                                       at the display's backing
                                       scale                     | B, G, R, A bytes,
                                                                   premultiplied             | B, G, R, A bytes,
                                                                                               premultiplied
| `pixels()` of a `make_image`
  image                              | The buffer's own format   | The buffer's own format   | B, G, R, A bytes,
                                                                                               premultiplied
|===

== Example

Render a badge once into an image, then paint it wherever it is needed:

```c++
   image badge{64, 64};
   {
      offscreen_image off{badge};
      canvas bc{off.context()};
      bc.add_circle(32, 32, 30);
      bc.fill_style(colors::gold);
      bc.fill();
   }

   cnv.draw(badge, {10, 10});
   cnv.draw(badge, {90, 10}, 0.5);
```
