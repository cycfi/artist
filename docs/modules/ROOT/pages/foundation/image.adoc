= Image

== Overview

An `image` is a bitmap the canvas can paint with `draw`, which is covered
under xref:canvas/images.adoc[Drawing Images]. This page covers the image
itself. There are three ways to get one: load it from a file, build it
from a buffer of pixels with `make_image`, or create a blank one of a
given size and draw into it through an `offscreen_image`.

Every image owns its pixels: 32 bit, premultiplied B, G, R, A, allocated
when the image is constructed. A blank image starts fully transparent.

An image's size is in units, the units the canvas draws in, and its scale
is the number of pixels per unit. An image made 64 by 64 at scale 2 holds
128 by 128 pixels, yet it is drawn, and drawn into, as 64 by 64. Use a
scale above 1 to render for a high density display without changing the
drawing code. Images loaded from a file or built with `make_image` have
scale 1.

A file name that is not absolute is looked up through the
xref:foundation/resources.adoc[Resources] search list. PNG, JPEG and WebP
are read on every backend; which other formats load depends on the
backend's decoder.

An `image` owns its storage, so it can be moved but not copied. Share one
through `image_ptr`, which is a `std::shared_ptr<image>`.

To draw into an image, construct an `offscreen_image` on it and build a
`canvas` on its `context()`. The drawing lands in the image as it is drawn,
over whatever the image already holds. The canvas must not outlive the
`offscreen_image`. The <<Example>> shows the pattern.

== Declaration

```c++
   enum class pixel_format
   {
      invalid = -1,
      gray8,
      rgb16,
      rgb32,
      rgba32,
   };
```

```c++
   class image
   {
   public:

      explicit          image(float sizex, float sizey, float scale = 1.0f);
      explicit          image(extent size, float scale = 1.0f);
      explicit          image(fs::path const& path_);

                        image(image const& rhs) = delete;
                        image(image&& rhs) noexcept;
                        ~image();

      image&            operator=(image const& rhs) = delete;
      image&            operator=(image&& rhs) noexcept;

      image_impl_ptr    impl() const;
      extent            size() const;
      float             scale() const;
      void              save_png(std::string_view path) const;

      uint32_t*         pixels();
      uint32_t const*   pixels() const;
      extent            bitmap_size() const;
   };

   using image_ptr = std::shared_ptr<image>;
```

```c++
   class offscreen_image
   {
   public:

      explicit          offscreen_image(image& img);
                        offscreen_image(offscreen_image const&) = delete;
                        ~offscreen_image();

      offscreen_image&  operator=(offscreen_image const& rhs) = delete;

      canvas_impl*      context() const;
   };
```


== Expressions

=== Notation

`img`, `img2`  :: Objects of type `image`.
`sx`, `sy`     :: `float` width and height, in units.
`sz`           :: Object of type `extent`, a width and height in units.
`s`            :: A `float`, a scale: pixels per unit.
`p`            :: Object of type `fs::path`, an image file name, relative
                  or absolute.
`str`          :: A `std::string_view`, a file name.
`d8`           :: A `std::uint8_t const*`, a buffer of pixels.
`d16`          :: A `std::uint16_t const*`, a buffer of pixels.
`d32`          :: A `std::uint32_t const*`, a buffer of pixels.
`off`          :: Object of type `offscreen_image`.

=== Constructors and Assignment

[cols="1,1"]
|===
| Expression                  | Semantics

| `image(sx, sy)`             | Construct a blank, fully transparent image
                                `sx` by `sy` units in size, at scale 1.
| `image(sx, sy, s)`          | As above, at scale `s`. The bitmap is
                                `sx * s` by `sy * s` pixels, rounded to
                                the nearest whole pixel.
| `image(sz)`                 | As `image(sz.x, sz.y)`.
| `image(sz, s)`              | As `image(sz.x, sz.y, s)`.
| `image(p)`                  | Load the image file `p`, at scale 1. Throws
                                `std::runtime_error` if the file is
                                missing or cannot be decoded.
| `image(std::move(img))`     | Move construct from `img`, which is left
                                holding nothing.
| `img = std::move(img2)`     | Move assign `img2` to `img`. `img2` is
                                left holding nothing.
|===

The constructors are `explicit`, so an `extent` or a path does not convert
to an `image` implicitly.

WARNING: A moved from `image` holds nothing. Destroy it or assign to it;
calling any other member on it is undefined behaviour.

=== Construction from Pixels

`make_image` builds an image from a buffer of `sz.x` by `sz.y` pixels,
stored row by row from the top with no padding between rows. The format is
a template argument, and each overload accepts only the formats that match
its pointer type, so `pixel_format::invalid` is rejected at compile time.

[cols="1,1,1"]
|===
| Expression                                    | Semantics                         | Return Type

| `make_image<pixel_format::gray8>(d8, sz)`     | Eight bit gray levels, one byte
                                                  per pixel. Opaque.                | `image`
| `make_image<pixel_format::rgb16>(d16, sz)`    | Sixteen bit 5-6-5 pixels, red in
                                                  the top five bits. Opaque.        | `image`
| `make_image<pixel_format::rgb32>(d32, sz)`    | Four bytes per pixel: R, G and B
                                                  in memory order, then a byte
                                                  that is ignored. Opaque.          | `image`
| `make_image<pixel_format::rgba32>(d32, sz)`   | Four bytes per pixel: R, G, B and
                                                  A in memory order, with straight
                                                  (not premultiplied) alpha.        | `image`
|===

The pixels are converted into the image's own bitmap, so the buffer can be
released as soon as `make_image` returns. The image has scale 1.

=== Accessors

[cols="1,1,1"]
|===
| Expression          | Semantics                              | Return Type

| `img.size()`        | The size of the image in units. `draw`
                        places the image at this size in user
                        space, and the `src` rectangle `draw`
                        takes is in these units.               | `extent`
| `img.scale()`       | The number of pixels per unit.         | `float`
| `img.bitmap_size()` | The width and height of the bitmap in
                        pixels, `size()` times `scale()`.      | `extent`
| `img.impl()`        | The backend's image handle, for code
                        that talks to the backend directly.    | `image_impl_ptr`
|===

=== Pixel Access

[cols="1,1,1"]
|===
| Expression      | Semantics                                  | Return Type

| `img.pixels()`  | The first pixel of the bitmap. Each pixel
                    is four bytes, B, G, R and A in memory
                    order, with the colour premultiplied by
                    alpha. Rows run from the top,
                    `bitmap_size().x` pixels to a row, with no
                    padding.                                   | `uint32_t*`, or
                                                                 `uint32_t const*`
                                                                 if `img` is
                                                                 `const`
|===

NOTE: Treat the buffer as read only. There is no call to tell the backend
that the pixels have changed, and Cairo needs one before it uses the image
again.

=== Output

[cols="1,1,1"]
|===
| Expression            | Semantics                            | Return Type

| `img.save_png(str)`   | Write the bitmap to the file `str` as
                          a PNG, `bitmap_size().x` by
                          `bitmap_size().y` pixels. `str` is
                          used as given; it is not looked up
                          through the resource search list.
                          Throws `std::runtime_error` if the
                          file cannot be written.              | `void`
|===

Loading the file back gives an image at scale 1, so its `size()` is the
saved image's `bitmap_size()`.

=== Offscreen Construction

[cols="1,1"]
|===
| Expression               | Semantics

| `offscreen_image(img)`   | Begin drawing into `img`, which must
                             outlive the `offscreen_image`.
|===

An `offscreen_image` is neither copyable nor movable. Its context draws
into the image in the image's units, scaled by `scale()` to pixels, and
each drawing call lands in the image as it is made. The destructor ends
the drawing.

=== Offscreen Context

[cols="1,1,1"]
|===
| Expression        | Semantics                              | Return Type

| `off.context()`   | The backend drawing context, from
                      which a `canvas` is built:
                      `canvas(off.context())`. Valid only
                      while `off` lives, so the canvas must
                      not outlive it.                        | `canvas_impl*`
|===

== Example

Render a badge once into an image, then paint it wherever it is needed.
At scale 2 the badge stays sharp on a high density display, and the
drawing code still works in its 64 unit size:

```c++
   image badge{64, 64, 2};
   {
      offscreen_image off{badge};
      canvas bc{off.context()};
      bc.add_circle(32, 32, 30);
      bc.fill_style(colors::gold);
      bc.fill();
   }

   cnv.draw(badge, {10, 10});
   cnv.draw(badge, {90, 10}, 0.5);
```
