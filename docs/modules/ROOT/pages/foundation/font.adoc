= Font

== Overview

A `font_descr` describes the font you want: one or more family names, a
size, and the attributes that pick a face within a family. A `font` is what that
description resolved to, a handle on a real face that the canvas can draw
with. You build the first, hand it to the second, and keep the result. It
is what `canvas::font()` takes, and it selects the face used by every
xref:canvas/text.adoc[Text] call that follows.

`font_descr` is a plain aggregate of five members with a chainable modifier
API. Every modifier is `const` and returns a modified copy, so a
description reads as one expression:

```c++
#include <artist/font.hpp>
...
using namespace cycfi::artist;
...
   auto fd = font_descr{"Open Sans", 14}.bold().italic();
```

The `_families` member is a comma separated list, searched left to right.
The first family the system offers wins. Within that family, Cairo, Skia
and recording pick the face closest to the requested slant, weight and
stretch, in that order of importance; Quartz 2D and Direct2D leave the
choice to the system's font manager. Direct2D searches the list only among
the application's own fonts; if none is there, it looks up the first
listed family alone among the system fonts. If none of the listed families
is present, construction still succeeds and never reports a failed
lookup, but what you get depends on the backend. Quartz 2D, Skia and
Direct2D fall back to a default system face. Cairo and recording hold an
empty face: its metrics are zero and `measure_text` returns zero.

image::foundation/font_metrics.svg[alt="Font metrics", width=560px, align=center, title="The three values metrics() reports, the line height they sum to, and the advance width measure_text() returns.", link={imagesdir}/foundation/font_metrics.svg]

Both `ascent` and `descent` are positive distances from the baseline, and
`leading` is the extra gap between one line's descent and the next line's
ascent. All four values, and the width `measure_text` returns, are in the
same units as `_size`, which is device units before the canvas
transformation matrix is applied.

NOTE: Fonts bundled with an application are found through
`get_user_fonts_directory()`, which the host application supplies. See
<<_client_interface>>.

TIP: On Cairo, Skia, Direct2D and recording the first `font` you construct
scans for fonts. Cairo, recording, and Skia on Linux list every font
fontconfig knows, the system's and the application's; Skia on macOS and
Windows, and Direct2D, read the font files in the application's directory.
That first construction is much more expensive
than the ones after it, so build the fonts you need up front rather than
inside a draw call.

NOTE: See xref:foundation.adoc[Foundation] for an overview of the foundation classes.

== Font Descriptor

=== Include

```c++
#include <artist/font.hpp>
```

=== Declaration

```c++
namespace font_constants
{
   enum weight_enum
   {
      thin              = 10,
      extra_light       = 20,
      light             = 30,
      weight_normal     = 40,
      medium            = 50,
      semi_bold         = 60,
      bold              = 70,
      extra_bold        = 80,
      black             = 90,
      extra_black       = 95,
   };

   enum slant_enum
   {
      slant_normal      = 0,
      italic            = 90,
      oblique           = 100
   };

   enum stretch_enum
   {
      ultra_condensed   = 25,
      extra_condensed   = 31,
      condensed         = 38,
      semi_condensed    = 44,
      stretch_normal    = 50,
      semi_expanded     = 57,
      expanded          = 63,
      extra_expanded    = 75,
      ultra_expanded    = 100
   };
}

struct font_descr
{
   font_descr           normal() const;
   font_descr           size(float size_) const;

   font_descr           weight(font_constants::weight_enum w) const;
   font_descr           thin() const;
   font_descr           extra_light() const;
   font_descr           light() const;
   font_descr           weight_normal() const;
   font_descr           medium() const;
   font_descr           semi_bold() const;
   font_descr           bold() const;
   font_descr           extra_bold() const;
   font_descr           black() const;
   font_descr           extra_black() const;

   font_descr           style(font_constants::slant_enum s) const;
   font_descr           slant_normal() const;
   font_descr           italic() const;
   font_descr           oblique() const;

   font_descr           stretch(font_constants::stretch_enum s) const;
   font_descr           ultra_condensed() const;
   font_descr           extra_condensed() const;
   font_descr           condensed() const;
   font_descr           semi_condensed() const;
   font_descr           stretch_normal() const;
   font_descr           semi_expanded() const;
   font_descr           expanded() const;
   font_descr           extra_expanded() const;
   font_descr           ultra_expanded() const;

   using slant_enum = font_constants::slant_enum;

   std::string_view     _families;
   float                _size = 12;
   uint8_t              _weight = font_constants::weight_normal;
   slant_enum           _slant = font_constants::slant_normal;
   uint8_t              _stretch = font_constants::stretch_normal;
};
```

=== Expressions

==== Notation

`fd`, `a`, `b`  :: Objects of type `font_descr`.
`fam`           :: Object of type `std::string_view` for a comma separated
                   list of font family names.
`sz`            :: Floating point value for the font size.
`w`             :: Value of type `font_constants::weight_enum`.
`sl`            :: Value of type `font_constants::slant_enum`.
`st`            :: Value of type `font_constants::stretch_enum`.

==== Type Definitions

[cols="1,1,1"]
|===
| Expression                | Semantics                 | Type

| `font_descr::slant_enum`  | Get the slant type.       | `font_constants::slant_enum`
|===

==== Constructors and Assignment

[cols="1,1"]
|===
| Expression                        | Semantics

| `font_descr{}`                    | Construct a `font_descr` with no
                                      families, size 12, and normal
                                      weight, slant and stretch.
| `font_descr\{fam}`                | Construct a `font_descr` given `fam`
                                      (families), with the defaults for
                                      the rest.
| `font_descr{fam, sz}`             | As above, given `sz` (size).
| `font_descr{fam, sz, w}`          | As above, given `w` (weight).
| `font_descr{fam, sz, w, sl}`      | As above, given `sl` (slant).
| `font_descr{fam, sz, w, sl, st}`  | As above, given `st` (stretch).
| `font_descr(fd)`                  | Copy construct from `font_descr fd`.
| `a = b`                           | Assign `b` to `a`.
|===

NOTE: `font_descr` has no user declared constructors. It is an aggregate,
initialized member by member in declaration order, and any member left out
takes its default.

NOTE: `_weight` and `_stretch` are stored as `uint8_t`, so brace
initialization accepts `w` and `st` only when they are constant
expressions; a runtime value is a narrowing conversion and does not
compile. `_slant` is stored as the enum itself, so an integer is never
accepted there. Use the modifiers under <<_operation>> for values computed
at run time.

WARNING: `_families` is a `std::string_view` and does not own its
characters. A `font_descr` built from a temporary `std::string` dangles as
soon as that string dies. String literals are safe.

==== Example

Describe a bold heading face, and a smaller italic caption face from it.

```c++
#include <artist/font.hpp>
...
using namespace cycfi::artist;
...
   auto heading = font_descr{"Open Sans, Helvetica", 24}.bold();   <1>
   auto caption = heading.size(12).normal().italic();              <2>
```

<1> Construct a descriptor for the first of the two families present, at
    size 24, and get a bold copy of it.
<2> Get a copy of the heading at size 12, with the weight back to normal,
    in italic.

== Font

=== Include

```c++
#include <artist/font.hpp>
```

=== Declaration

```c++
class font
{
public:
                        font();
                        font(font_descr descr);
                        font(font const& rhs);
                        font(font&& rhs) noexcept;
                        ~font();

   font&                operator=(font const& rhs);
   font&                operator=(font&& rhs) noexcept;
   explicit             operator bool() const;
   font_impl_ptr        impl() const;

   struct metrics_info
   {
      float             ascent;
      float             descent;
      float             leading;
   };

   metrics_info         metrics() const;
   float                line_height() const;
   float                measure_text(std::string_view str) const;
};
```

=== Expressions

==== Notation

`f`, `a`, `b`   :: Objects of type `font`.
`fd`            :: Object of type `font_descr`.
`str`           :: Object of type `std::string_view`.

==== Type Definitions

[cols="1,1,1"]
|===
| Expression            | Semantics                     | Type

| `font::metrics_info`  | Get the metrics type, with
                          the `float` members
                          `ascent`, `descent` and
                          `leading`.                    | `struct`
|===

==== Constructors and Assignment

[cols="1,1"]
|===
| Expression              | Semantics

| `font()`                | Construct a `font` with no descriptor. What
                            it holds depends on the backend (see the
                            NOTE under <<_accessors>>).
| `font(fd)`              | Construct a `font` given `fd`, holding the
                            face it names, or the backend's fallback if
                            no listed family is present (see the
                            Overview).
| `font(f)`               | Copy construct from `font f`. The copy names
                            the same face.
| `font(std::move(f))`    | Move construct from `f`, which is left
                            holding no face.
| `a = b`                 | Assign `b` to `a`.
| `a = std::move(b)`      | Move assign `b` to `a`. On Cairo, Skia and
                            recording `b` is left holding no face; on
                            Quartz 2D and Direct2D the two are swapped,
                            so `b` holds the face `a` held before.
|===

NOTE: C++ brace initialization may also be used.

WARNING: A `font` moved from by construction holds no face, as does one
moved from by assignment on Cairo, Skia and recording. Calling
`metrics()`, `line_height()` or `measure_text()` on it is undefined
behaviour.

==== Access

[cols="1,1,1"]
|===
| Expression              | Semantics                  | Return Type

| `f.metrics().ascent`    | Access the distance from
                            the baseline up to the top
                            of the face, positive.     | `float`
| `f.metrics().descent`   | Access the distance from
                            the baseline down to the
                            bottom of the face,
                            positive.                  | `float`
| `f.metrics().leading`   | Access the extra space
                            between one line's descent
                            and the next line's
                            ascent.                    | `float`
|===

==== Accessors

[cols="1,1,1"]
|===
| Expression              | Semantics                  | Return Type

| `f.metrics()`           | Get the ascent, descent
                            and leading of `f`.        | `font::metrics_info`
| `f.line_height()`       | Get the sum of the three,
                            the baseline to baseline
                            distance for single spaced
                            text.                      | `float`
| `f.measure_text(str)`   | Get the advance width
                            `str` occupies when drawn
                            with `f`. The canvas
                            transformation matrix is
                            not taken into account.    | `float`
| `bool(f)`               | Test whether `f` holds a
                            backend handle. The
                            conversion is `explicit`.  | `bool`
| `f.impl()`              | Get the backend handle,
                            for calling the backend
                            directly: an `SkFont`
                            shared pointer under Skia,
                            an opaque `font_impl*`
                            otherwise.                 | `font_impl_ptr`
|===

NOTE: What `bool(f)` reports for a default constructed `font` depends on
the backend: Quartz 2D and Direct2D leave the handle null, while Cairo
and recording build an empty one and Skia a default `SkFont`, so on those
three `bool(f)` is `true` and the metrics calls are safe. Construction
from a descriptor always yields a handle on every backend. Use the
conversion to test a moved from `font`, not to check whether a family was
found.

==== Example

Build a heading font once, then use its metrics to stack two lines and
right align the second under the first.

```c++
#include <artist/font.hpp>
#include <artist/canvas.hpp>             // For canvas
...
using namespace cycfi::artist;
extern canvas cnv;                       // the canvas to draw on
...
   float x = 40, y = 50;
   auto heading = font{font_descr{"Open Sans, Helvetica", 24}.bold()};  <1>

   cnv.font(heading);                                                    <2>
   cnv.fill_style(colors::black);
   cnv.fill_text("Artist", {x, y});

   auto lh = heading.line_height();                                      <3>
   auto dx = heading.measure_text("Artist")                              <4>
           - heading.measure_text("2D Canvas");

   cnv.fill_text("2D Canvas", {x + dx, y + lh});
```

<1> Construct the font once, from a bold descriptor.
<2> Select it on the canvas for the text calls that follow.
<3> Get the baseline to baseline distance for the second line.
<4> Get the difference in width of the two lines. It is negative here,
    because "2D Canvas" is the wider of the two, so the second line starts
    further left and the two end together.

== Client Interface

`get_user_fonts_directory()` is declared by the library and defined by
the host application. Cairo, Skia, Direct2D and recording call it once, to
register every font file in that directory alongside the system fonts.
Quartz 2D never calls it: a macOS application registers its bundled fonts
itself, as the examples do through `ATSApplicationFontsPath` in their
`Info.plist`.

`fs::path get_user_fonts_directory();` ::
    Get the directory holding the application's own font files. Example:
    `resources/fonts` under the current directory.

Every host under `examples/host/` defines it, next to
xref:foundation/resources.adoc#_client_interface[`init_paths`]:

```c++
#include <artist/font.hpp>
...
namespace cycfi::artist
{
   fs::path get_user_fonts_directory()
   {
      return fs::current_path() / "resources/fonts";
   }
}
```
