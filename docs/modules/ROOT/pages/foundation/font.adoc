= Font

== Overview

A `font_descr` says what font you want: one or more family names, a size,
and the attributes that pick a face within a family. A `font` is what that
description resolved to, a handle on a real face that the canvas can draw
with. You build the first, hand it to the second, and keep the result. It
is what `canvas::font()` takes, and it selects the face used by every
xref:canvas/text.adoc[Text] call that follows.

`font_descr` is a plain aggregate of five members with a chainable modifier
API. Every modifier is `const` and returns a modified copy, so a
description reads as one expression:

```c++
   font_descr{"Open Sans", 14}.bold().italic()
```

The `_families` member is a comma separated list, searched left to right.
The first family the system offers wins, and within that family the
backend picks the face closest to the requested slant, weight and stretch,
in that order of importance. If none of the listed families is present,
construction still succeeds: every backend falls back to a default face.
A `font` built from a descriptor is therefore always usable, and never
reports a failed lookup.

image::foundation/font_metrics.svg[alt="Font metrics", width=560px, align=center, title="The three values metrics() reports, the line height they sum to, and the advance width measure_text() returns.", link={imagesdir}/foundation/font_metrics.svg]

Both `ascent` and `descent` are positive distances from the baseline, and
`leading` is the extra gap between one line's descent and the next line's
ascent. All four values, and the width `measure_text` returns, are in the
same units as `_size`, which is device units before the canvas
transformation matrix is applied.

NOTE: Fonts bundled with an application are found through
`get_user_fonts_directory()`. The library declares that function but does
not define it: the host application supplies it, and the backends call it
once to register every font file in that directory alongside the system
fonts.

TIP: On the Skia and Cairo backends the first `font` you construct scans
the system and application font directories to build a family map. That
first construction is much more expensive than the ones after it, so
build the fonts you need up front rather than inside a draw call.

== Expressions

=== Notation

`fd`, `fd2`    :: Objects of type `font_descr`.
`f`, `f2`      :: Objects of type `font`.
`fam`          :: A `std::string_view`, a comma separated list of font
                  family names.
`sz`           :: A `float`, the font size.
`w`            :: A `font_constants::weight_enum`.
`sl`           :: A `font_constants::slant_enum`.
`st`           :: A `font_constants::stretch_enum`.
`str`          :: An object of type `std::string_view`.

=== Descriptor Construction

`font_descr` has no user declared constructors. It is an aggregate,
initialised member by member in declaration order, and any member left out
takes its default.

[cols="1,1"]
|===
| Expression                        | Semantics

| `font_descr{}`                    | Default construct: no families,
                                      size 12, normal weight, slant and
                                      stretch.
| `font_descr\{fam}`                | Construct with the family list
                                      `fam` and the defaults for the rest.
| `font_descr{fam, sz}`             | As above, with size `sz`.
| `font_descr{fam, sz, w}`          | As above, with weight `w`.
| `font_descr{fam, sz, w, sl}`      | As above, with slant `sl`.
| `font_descr{fam, sz, w, sl, st}`  | As above, with stretch `st`.
| `font_descr(fd)`                  | Copy construct from `fd`.
| `fd = fd2`                        | Assign `fd2` to `fd`.
|===

IMPORTANT: `_weight` and `_stretch` are stored as `uint8_t`, so brace
initialisation accepts `w` and `st` only when they are constant
expressions; a runtime value is a narrowing conversion and will not
compile. `_slant` is stored as the enum itself, so an integer is never
accepted there. Use the modifiers below for values computed at run time.

WARNING: `_families` is a `std::string_view` and does not own its
characters. A `font_descr` built from a temporary `std::string` dangles as
soon as that string dies. String literals are safe.

=== Size and Defaults

Each returns a modified copy; `fd` is not touched.

[cols="1,1,1"]
|===
| Expression        | Semantics                          | Return Type

| `fd.size(sz)`     | Copy of `fd` with size `sz`.       | `font_descr`
| `fd.normal()`     | Copy of `fd` with weight, slant
                      and stretch reset to their normal
                      values. Families and size are
                      left alone.                        | `font_descr`
|===

=== Descriptor Members

The members are public and may be read or written directly.

[cols="1,1,1"]
|===
| Expression       | Semantics                       | Return Type

| `fd._families`   | The comma separated family
                     list.                           | `std::string_view`
| `fd._size`       | The font size.                  | `float`
| `fd._weight`     | The weight, 10 to 95.           | `uint8_t`
| `fd._slant`      | The slant, 0 to 100.            | `slant_enum`
| `fd._stretch`    | The stretch, 25 to 100.         | `uint8_t`
|===

=== Font Construction and Assignment

[cols="1,1"]
|===
| Expression              | Semantics

| `font{}`                | Default construct. The result names no face
                            and is not usable for drawing.
| `font(fd)`              | Resolve the descriptor `fd` and hold the face
                            it names, or the backend's fallback face if no
                            listed family is present.
| `font(f)`               | Copy construct from `f`. The copy names the
                            same face.
| `font(std::move(f))`    | Move construct from `f`, which is left
                            holding no face.
| `f = f2`                | Assign `f2` to `f`.
| `f = std::move(f2)`     | Move assign `f2` to `f`, which is left
                            holding no face.
|===

WARNING: A moved from `font` holds no face. Calling `metrics()`,
`line_height()` or `measure_text()` on it is undefined behaviour.

=== Font Validity and Access

[cols="1,1,1"]
|===
| Expression   | Semantics                            | Return Type

| `bool(f)`    | Whether `f` holds a backend handle.
                 The conversion is `explicit`.        | `bool`
| `f.impl()`   | The backend handle, for code that
                 needs to talk to the backend
                 directly. An `SkFont` shared
                 pointer under Skia, an opaque
                 `font_impl*` otherwise.              | `font_impl_ptr`
|===

NOTE: What `bool(f)` reports for a default constructed `font` depends on
the backend: Quartz 2D leaves the handle null, while Skia and Cairo build
an empty one. Construction from a descriptor always yields a handle on
every backend. Use the conversion to test a moved from `font`, not to
check whether a family was found.

=== Font Metrics

[cols="1,1,1"]
|===
| Expression              | Semantics                  | Return Type

| `f.metrics()`           | The ascent, descent and
                            leading of `f`.            | `font::metrics_info`
| `f.metrics().ascent`    | Distance from the baseline
                            up to the top of the
                            face, positive.            | `float`
| `f.metrics().descent`   | Distance from the baseline
                            down to the bottom of the
                            face, positive.            | `float`
| `f.metrics().leading`   | Extra space between one
                            line's descent and the
                            next line's ascent.        | `float`
| `f.line_height()`       | The sum of the three, the
                            baseline to baseline
                            distance for single
                            spaced text.               | `float`
| `f.measure_text(str)`   | The advance width `str`
                            occupies when drawn with
                            `f`. The canvas
                            transformation matrix is
                            not taken into account.    | `float`
|===

=== Free Functions

[cols="1,1,1"]
|===
| Expression                    | Semantics             | Return Type

| `get_user_fonts_directory()`  | The directory holding
                                  the application's own
                                  font files. Declared
                                  by the library and
                                  defined by the host
                                  application.          | `fs::path`
|===

== Example

Build a heading font once, then use its metrics to stack two lines and
right align the second under the first:

```c++
   auto heading = font{font_descr{"Open Sans, Helvetica", 24}.bold()};

   cnv.font(heading);
   cnv.fill_text("Artist", {x, y});

   auto lh = heading.line_height();
   auto dx = heading.measure_text("Artist")
           - heading.measure_text("2D Canvas");

   cnv.fill_text("2D Canvas", {x + dx, y + lh});
```
