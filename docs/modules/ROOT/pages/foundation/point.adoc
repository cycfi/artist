= Point and Extent

== Overview

A `point` is a position in the 2D cartesian coordinate space: two `float`
members, `x` and `y`. An `extent` is the same pair of numbers used to mean
a size rather than a position. `extent` derives from `point` and deletes
the three members that only make sense for a position, so a size cannot be
moved or reflected by accident.

`point` and `extent` are the two types the rest of the library measures
with. xref:foundation/rect.adoc[`rect`] is built from them,
xref:foundation/circle.adoc[`circle::center()`] returns a `point`, and
`affine_transform::apply` maps one.

The header also defines `axis`, a two valued enumeration used to write
code once and run it on either coordinate. `point` is subscriptable by it,
and xref:foundation/rect.adoc[`rect`] has a family of `axis` free
functions built on the same idea.

Everything on this page is `constexpr`, construction and accessors alike,
so points and extents can be computed at compile time. This is the
opposite of xref:foundation/circle.adoc[`circle`], where only the
constructors are.

NOTE: An `extent` names its members `x` and `y`, not `width` and `height`.
The width is `e.x` and the height is `e.y`. Only
xref:foundation/rect.adoc[`rect`] spells the two out, through `width()`
and `height()`.

== Include

```c++
#include <artist/point.hpp>
```

== Declaration

```c++
   enum class axis : bool { x = false, y = true };

   constexpr axis other(axis a);
```

```c++
   struct point
   {
      constexpr         point();
      constexpr         point(float x, float y);
      constexpr         point(point const&) = default;
      constexpr point&  operator=(point const&) = default;

      constexpr bool    operator==(point const& other) const;
      constexpr bool    operator!=(point const& other) const;

      constexpr point   move(float dx, float dy) const;
      constexpr point   move_to(float x, float y) const;
      constexpr point   reflect(point p) const;

      constexpr float&  operator[](axis a);
      constexpr float   operator[](axis a) const;

      float             x;
      float             y;
   };
```

```c++
   struct extent : point
   {
      using point::point;

      constexpr         extent(point p);

      point             move(float dx, float dy) const = delete;
      point             move_to(float x, float y) const = delete;
      point             reflect(point p) const = delete;
   };
```

== Expressions

=== Notation

`p`, `p2`         :: Objects of type `point`.
`e`, `e2`         :: Objects of type `extent`.
`a`               :: Object of type `axis`.
`x`, `y`          :: Floating point coordinates.
`dx`, `dy`        :: Floating point distances.

=== Axis

[cols="1,1,1"]
|===
| Expression    | Semantics                                  | Return Type

| `axis::x`     | The horizontal axis. Converts to `false`.  | `axis`
| `axis::y`     | The vertical axis. Converts to `true`.     | `axis`
| `other(a)`    | The axis that `a` is not.                  | `axis`
|===

The underlying type is `bool`, so an `axis` is one byte and
`bool(axis::y)` is `true`. The enumeration is scoped, so the conversion
has to be written out.

=== Point Construction and Assignment

[cols="1,1"]
|===
| Expression       | Semantics

| `point{}`        | Default construct `{0, 0}`, the origin.
| `point{x, y}`    | Construct from the two coordinates.
| `point(p)`       | Copy construct from `p`.
| `p = p2`         | Assign `p2` to `p`.
|===

NOTE: `point` has user declared constructors, so it is not an aggregate.
Both members are always set: there is no way to get a partly initialized
`point`, and `point{}` is the origin rather than indeterminate.

CAUTION: The members are `float`, and brace initialization forbids
narrowing. `point{1, 2}` compiles because the literals convert exactly,
but `point{n, 2}` with an `int` variable `n` does not. Write
`point(n, 2)` with parentheses, or convert at the call site.

=== Comparison

[cols="1,1,1"]
|===
| Expression   | Semantics                                   | Return Type

| `p == p2`    | Compare `x` and `y`. The comparison is
                 exact, so two points differing only by
                 rounding are not equal.                     | `bool`
| `p != p2`    | The negation of the above.                  | `bool`
|===

=== Members

The members are public and directly assignable.

[cols="1,1,1"]
|===
| Expression  | Semantics                                    | Return Type

| `p.x`       | The x coordinate.                            | `float`
| `p.y`       | The y coordinate.                            | `float`
|===

=== Subscript

[cols="1,1,1"]
|===
| Expression  | Semantics                                    | Return Type

| `p[a]`      | The coordinate on axis `a`: `x` for
                `axis::x`, `y` for `axis::y`. On a
                non-const `point` this is a reference, so
                `p[a] = v` assigns the member.                | `float&`
| `p[a]`      | The same on a const `point`, by value.       | `float`
|===

Subscript is what makes an algorithm axis agnostic. A routine that snaps
along one axis can take an `axis` parameter, use `p[a]` throughout, and
work in both directions without a second copy.

=== Derivation

Each is `const` and returns a new `point`; `p` is not modified.

[cols="1,1,1"]
|===
| Expression          | Semantics                            | Return Type

| `p.move(dx, dy)`    | A copy of `p` displaced by `dx` and
                        `dy`.                                | `point`
| `p.move_to(x, y)`   | A copy of `p` placed at `{x, y}`,
                        which discards the original
                        coordinates.                         | `point`
| `p.reflect(p2)`     | The reflection of `p2` through `p`,
                        which is `{2x - p2.x, 2y - p2.y}`.   | `point`
|===

CAUTION: `reflect` reflects its *argument*, not the object it is called
on. `p.reflect(p2)` treats `p` as the centre of rotation and returns `p2`
rotated 180 degrees about it, so `point(0, 0).reflect(point(3, 4))` is
`{-3, -4}`. The reading suggested by the name, reflecting `p` about `p2`,
is `p2.reflect(p)`.

=== Extent Construction and Assignment

[cols="1,1"]
|===
| Expression       | Semantics

| `extent{}`       | Default construct `{0, 0}`, an empty size.
| `extent{x, y}`   | Construct from the width and the height, through
                     the inherited `point` constructor.
| `extent(p)`      | Construct from a `point`, taking `p.x` as the
                     width and `p.y` as the height.
| `extent(e)`      | Copy construct from `e`.
| `e = e2`         | Assign `e2` to `e`.
|===

Both coordinates are required. `+extent{10}+` does not compile: there is no
one argument constructor, and the inherited `point` constructor takes two.

=== Extent and Point

`extent` publicly derives from `point` and its `point` constructor is not
explicit, so the two convert freely in both directions.

[cols="1,1,1"]
|===
| Expression   | Semantics                                   | Return Type

| `e.x`        | The width.                                  | `float`
| `e.y`        | The height.                                 | `float`
| `e[a]`       | The size along axis `a`. Subscript is
                 inherited and not deleted.                  | `float&`
| `e == e2`    | Componentwise, through `point::operator==`.
                 `e == p` and `p == e` compile too.          | `bool`
| `e.move(dx, dy)` +
  `e.move_to(x, y)` +
  `e.reflect(p)`
               | Deleted. Each is a compile error.           | deleted
|===

The three deleted members hide the base versions rather than removing
them, so `static_cast<point const&>(e).move(dx, dy)` still compiles. That
is the escape hatch when a size genuinely has to be treated as a position.

IMPORTANT: The separation is a naming aid, not a type barrier. `extent e =
p;` and `point p = e;` both compile silently, so passing a position where
a size is expected is not caught. Only the three deleted members are
enforced.

== Example

An axis agnostic helper that grows a `point` along one axis only, and the
`extent` returned by a `rect`:

```c++
   constexpr point advance(point p, axis a, float d)
   {
      p[a] += d;
      return p;
   }

   constexpr auto p = advance(point(10, 20), axis::y, 5);   // {10, 25}

   // rect::size() hands back an extent; x is the width, y the height.
   auto size = bounds.size();
   auto square = std::min(size.x, size.y);
```
