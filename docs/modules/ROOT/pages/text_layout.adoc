= Text Layout

== Overview

A `text_layout` is a document of text. Its text is split into paragraphs at
each line feed, `'\n'`, and each paragraph is laid out by its own
xref:text_run.adoc[text_run], the paragraphs stacked one line height
apart. It can be edited in place: `insert`, `erase` and `replace` shape
again only the paragraphs an edit touches, which keeps a long document
responsive in an editor. `make_text_layout` builds one in a single font.

A `text_layout` keeps the width it was last flowed to. Replacing or editing
the text lays the result out again at that width, so, unlike a `text_run`,
it needs no fresh `flow` after a change. Before the first flow, each
paragraph counts as one line.

Positions are in document coordinates, with y = 0 at the top of the first
line. Every line is a box one line height tall: line _k_ spans y from _k_
times the line height to _k_ + 1 times it. `caret_point` gives the top of
a caret's line, and `caret_index` picks the line whose box holds the point.
`draw` is the exception: as for a `text_run`, its point is the left end of
the first line's baseline, so draw at the top plus the font's ascent.
Indices are code point indices into `text()`.

The tints are the line boxes caret_point and caret_index work in; the dots mark the document's top-left and the draw point p on the first baseline.", link={imagesdir}/text_layout/example.png]

NOTE: Hit testing is where a `text_layout` and a `text_run` differ. A
`text_run` picks a line by baselines, so a point just below one baseline
already belongs to the next line. A `text_layout` picks it by line box,
which is what an editor wants from a click.

`text_layout` is `basic_text_layout<text_run>`. The template takes the
paragraph type as a parameter, so another type can stand in, such as a
non-graphical one for tests; see <<TextRun Requirements>>.

== Include

```c++
#include <artist/text_layout.hpp>
```

== Declaration

```c++
template <typename TextRun>
class basic_text_layout
{
public:

   using size_type = std::size_t;
   using factory = std::function<TextRun(std::u32string_view)>;
   using break_enum = typename TextRun::break_enum;

   static constexpr size_type npos = size_type(-1);

                           basic_text_layout(
                              factory make
                            , double line_height
                            , std::u32string_view text
                           );

                           basic_text_layout(basic_text_layout&&) noexcept = default;
   basic_text_layout&      operator=(basic_text_layout&&) noexcept = default;

   void                    set_text(std::u32string_view text);
   std::u32string          text() const;
   size_type               size() const;
   size_type               paragraph_count() const;

   void                    insert(size_type pos, std::u32string_view text);
   void                    erase(size_type pos, size_type len);
   void                    replace(size_type pos, size_type len, std::u32string_view text);

   void                    flow(float width, bool justify = false);
   size_type               num_lines() const;
   double                  height() const;
   size_type               paragraph_lines(size_type i) const;

   point                   caret_point(size_type index) const;
   size_type               caret_index(point p) const;
   size_type               caret_index(float x, float y) const;

   break_enum              word_break(size_type index) const;
   break_enum              line_break(size_type index) const;

   void                    draw(canvas& cnv, point p, color c = colors::black) const;
};

using text_layout = basic_text_layout<text_run>;

text_layout make_text_layout(font_descr f, std::u32string_view text);
```

== Expressions

=== Notation

`TextRun`         :: A type that meets the <<TextRun Requirements>>.
`tl_type`         :: A `basic_text_layout<TextRun>` type.
`d`, `a`, `b`     :: Objects of type `tl_type`.
`r`               :: Object of type `TextRun`.
`make`            :: Object of type `tl_type::factory`.
`lh`              :: Floating point value for the line height.
`f`               :: Object of type `font_descr`.
`s`               :: Object of type `std::u32string_view`.
`pos`, `i`        :: `tl_type::size_type` values, code point indices into
                     `d.text()`.
`len`             :: `tl_type::size_type` value, a number of code points.
`k`               :: `tl_type::size_type` value, a paragraph index.
`n`               :: `std::size_t` value, a code point index into one
                     paragraph.
`w`               :: Floating point value for the line width.
`j`               :: `bool` value, whether to justify.
`cnv`             :: Object of type `canvas`.
`p`               :: Object of type `point`.
`x`, `y`          :: Floating point values for the coordinates of a point.
`c`               :: Object of type `color`.

=== Type Construction

[cols="1,1"]
|===
| Expression                    | Semantics

| `basic_text_layout<TextRun>`  | Instantiate a `basic_text_layout` type

==== TextRun Requirements

`TextRun` is move constructible, declares `TextRun::break_enum`, the type
its break queries return, and allows these expressions.

[cols="1,1,1"]
|===
| Expression              | Semantics                          | Return Type

| `TextRun::must_break`   | Get the `break_enum` value for a
                            required break. Needed only if
                            `d.line_break(i)` is used.         | `TextRun::break_enum`
| `r.flow(w, j)`          | Lay the paragraph out in lines no
                            wider than `w`, justified if `j`
                            is `true`.                         | any
| `r.num_lines()`         | Get the paragraph's line count; 0
                            is taken as one line.              | convertible to `std::size_t`
| `r.caret_point(n)`      | Get the paragraph-local caret
                            position before `n`, with the y of
                            line _k_ at _k_ times the line
                            height.                            | `point`
| `r.caret_index(p)`      | Get the paragraph-local index
                            nearest `p`, choosing a line by
                            baselines as a `text_run` does.    | convertible to `std::size_t`
| `r.word_break(n)`       | Get the word break after `n`.
                            Needed only if `d.word_break(i)`
                            is used.                           | `TextRun::break_enum`
| `r.line_break(n)`       | Get the line break after `n`.
                            Needed only if `d.line_break(i)`
                            is used.                           | `TextRun::break_enum`
| `r.draw(cnv, p, c)`     | Draw the paragraph in the colour
                            `c`, with its first baseline at
                            `p`. Needed only if
                            `d.draw(cnv, p [, c])` is used.    | any
|===

=== Type Definitions

[cols="1,1,1"]
|===
| Expression              | Semantics                          | Type

| `tl_type::size_type`    | Get the size and index type.       | `std::size_t`
| `tl_type::factory`      | Get the type of the function that
                            builds each paragraph's
                            `TextRun`.                         | `std::function<TextRun(std::u32string_view)>`
| `tl_type::break_enum`   | Get the type the break queries
                            return.                            | `TextRun::break_enum`
|===

=== Constructors and Assignment

[cols="1,1"]
|===
| Expression                  | Semantics

| `tl_type(make, lh, s)`      | Construct a `basic_text_layout` over the
                                text `s`, with lines `lh` apart, and
                                `make` building the `TextRun` for each
                                paragraph. The text is not yet flowed.
| `tl_type(std::move(d))`     | Move construct from `tl_type d`, leaving
                                `d` holding nothing.
| `a = std::move(b)`          | Move assign `b` to `a`, leaving `b`
                                holding nothing.
|===

NOTE: C++ brace initialization may also be used.

A `basic_text_layout` can be moved but not copied.

WARNING: A moved from `basic_text_layout` holds nothing. Destroy it or
assign to it; calling any other member on it is undefined behaviour.

[cols="1,1,1"]
|===
| Expression        | Semantics                                | Return Type

| `tl_type::npos`   | Access `size_type(-1)`, kept to match
                      `text_run::npos`. `caret_index` does not

|===

=== Accessors

[cols="1,1,1"]
|===
| Expression              | Semantics                          | Return Type

| `d.text()`              | Get the whole text, as a copy.     | `std::u32string`
| `d.size()`              | Get the number of code points.     | `tl_type::size_type`
| `d.paragraph_count()`   | Get the number of paragraphs, one
                            more than the number of line
                            feeds. A text that ends in a line
                            feed ends in an empty paragraph.   | `tl_type::size_type`
| `d.num_lines()`         | Get the number of lines over all
                            the paragraphs. An empty paragraph
                            counts as one line.                | `tl_type::size_type`
| `d.height()`            | Get `num_lines()` times the line
                            height.                            | `double`
| `d.paragraph_lines(k)`  | Get the number of lines paragraph
                            `k` takes.                         | `tl_type::size_type`
| `d.caret_point(i)`      | Get the caret position before code
                            point `i`: the left edge of its
                            glyph, at the top of its line. An
                            `i` at or past the end gives the
                            end of the last line.              | `point`
| `d.caret_index(p)`      | Get the index of the caret
                            position nearest `p`, in the line
                            whose box holds `p.y`.             | `tl_type::size_type`
| `d.caret_index(x, y)`   | Get the index of the caret
                            position nearest the point at `x`,
                            `y`, as `d.caret_index(p)`.        | `tl_type::size_type`
| `d.line_break(i)`       | Get the line break after `i`, as
                            `text_run::line_break`, over the
                            whole text. A line feed at `i`
                            reports a required break after
                            it.                                | `tl_type::break_enum`
| `d.word_break(i)`       | Get the word break after `i`, as
                            `text_run::word_break`, over the
                            whole text.                        | `tl_type::break_enum`
|===

A point above the text maps to the first line and one below it to the
last, so `caret_index` always returns an index. Within the line, `x` is
resolved as a `text_run` resolves it.

=== Mutators

[cols="1,1,1"]
|===
| Expression              | Semantics                          | Return Type

| `d.set_text(s)`         | Set the whole text to `s`, laid
                            out again at the current width.    | `void`
|===

=== Operation

[cols="1,1,1"]
|===
| Expression                | Semantics                        | Return Type

| `d.insert(pos, s)`        | Insert `s` before code point
                              `pos`. A `pos` past the end
                              appends. Inserting empty text
                              does nothing.                    | `void`
| `d.erase(pos, len)`       | Remove `len` code points from
                              `pos`, stopping at the end.
                              Nothing happens if `len` is 0
                              or `pos` is at or past the end.  | `void`
| `d.replace(pos, len, s)`  | Replace `len` code points from
                              `pos` with `s`, as
                              `d.erase(pos, len)` followed by
                              `d.insert(pos, s)`.              | `void`
| `d.flow(w [, j])`         | Lay every paragraph out in lines
                              no wider than `w`, and justify
                              them if `j` is `true`. Default:
                              `j=false`.                       | `void`
| `d.draw(cnv, p [, c])`    | Draw the text in the colour `c`,
                              with the first line's baseline
                              starting at `p`. Default:
                              `c=colors::black`.               | `void`
|===

An edit shapes again only the paragraphs it touches; the others keep their
layout and move up or down. Inserting a line feed splits a paragraph, and
removing one joins two. The edited text is laid out at the current width.

Flowing again at the same width and justification does nothing, so an
editor can call `flow` after every edit, to read the new `height()`, at no
cost. Lines break and justify as they do in a
xref:text_run.adoc[text_run].

Only the paragraphs that intersect the canvas's clip are drawn, so drawing
a long document in a scrolled view costs what is visible.

=== Factory

[cols="1,1,1"]
|===
| Expression                  | Semantics                      | Return Type

| `make_text_layout(f, s)`    | Make a `text_layout` over the
                                text `s` in the font `f`, with
                                the font's `line_height()` as
                                its line height. The text is
                                not yet flowed.                | `text_layout`
|===

=== Example

Build a document from `text`, append a paragraph after the flow, and draw
a caret where the mouse position `mp` falls.

```c++
#include <artist/text_layout.hpp>
#include <artist/canvas.hpp>    // For canvas
#include <string_view>
...
using namespace cycfi::artist;
extern canvas cnv;              // the canvas to draw on
std::u32string_view text;       // the document's text, UTF-32
point mp;                       // the mouse position
...
   auto fd = font_descr{"Open Sans", 20};
   auto fm = font{fd}.metrics();
   auto lh = font{fd}.line_height();

   auto doc = make_text_layout(fd, text);                            <1>
   doc.flow(340);                                                    <2>
   doc.insert(doc.size(), U"\nThis paragraph was added after the flow.");  <3>

   auto top_left = point{90, 30};
   doc.draw(cnv, {top_left.x, top_left.y + fm.ascent});              <4>

   auto i = doc.caret_index(mp.x - top_left.x, mp.y - top_left.y);   <5>
   auto cp = doc.caret_point(i);                                     <6>
   cnv.stroke_style(colors::navy);
   cnv.move_to(top_left.x + cp.x, top_left.y + cp.y);
   cnv.line_to(top_left.x + cp.x, top_left.y + cp.y + lh);
   cnv.stroke();
```

<1> Make a document over `text` in a 20 point Open Sans.
<2> Flow it to a width of 340.
<3> Append a paragraph. It is laid out at the width of the last flow.
<4> Draw the document with its top at `top_left`, the first baseline one
    ascent below it.
<5> Find the caret index nearest the mouse, in document coordinates.
<6> Get the top of the caret's line, and stroke a caret one line height
    tall from there.

Its output is the figure in the <<Overview>>.
