= Text Run

== Overview

A `text_run` is one paragraph of text in one font, shaped, broken into
lines to fit a width, and then drawn and hit tested as a unit. It keeps its
own copy of the text as UTF-32. `text_layout`, the multi-paragraph editor
engine, is built from one `text_run` per paragraph.

Using one takes three steps: construct it, `flow` it to a width, and
`draw` it. A run has no lines until it has been flowed, and replacing its
text discards them, so flow again after every change of text.

Positions are relative to the run's origin, the point on the first line's
baseline where a line with no offset would start: `draw(cnv, p)` puts the
origin at `p`, and every `caret_point` y is a baseline. Indices are code
point indices into `text()`, not UTF-8 byte offsets.

image::text_run/example.png[alt="Output of the example", width=560px, align=center, title="The output of the Example below, annotated. The caret is where mp falls, and the tint is the band caret_index maps to its line: it runs from the previous baseline down to this one.", link={imagesdir}/text_run/example.png]

A run draws with its own font and the colour it is given. The canvas
font, fill style and text alignment play no part; the canvas transform
does apply.

NOTE: Lines are wrapped at the opportunities `line_break` reports, except
on Quartz 2D and Direct2D, where Core Text and DirectWrite both shape and
wrap the text. There a wrap can fall somewhere `line_break` does not mark,
and the same text can wrap differently from other backends.

== Include

```c++
#include <artist/text_run.hpp>
```

== Declaration

```c++
class text_run : non_copyable
{
public:

   struct line_info
   {
      float    offset;
      float    width;
   };

   struct flow_info
   {
      bool     justify;
      float    line_height;
      float    last_line_height;
   };

   enum break_enum { indeterminate, must_break, allow_break, no_break };

   using get_line_info = std::function<line_info(float y)>;
   static constexpr auto npos = std::size_t(-1);

                           text_run(font_descr font_, std::string_view utf8);
                           text_run(font_descr font_, std::u32string_view utf32);
                           text_run(text_run&& rhs) noexcept;
                           ~text_run();

   void                    text(std::string_view utf8);
   void                    text(std::u32string_view utf32);
   std::u32string_view     text() const;

   void                    flow(float width, bool justify = false);
   void                    flow(get_line_info const& glf, flow_info finfo);
   void                    draw(canvas& cnv, point p, color c = colors::black) const;
   void                    draw(canvas& cnv, float x, float y, color c = colors::black) const;

   std::size_t             num_lines() const;
   point                   caret_point(std::size_t index) const;
   std::size_t             caret_index(float x, float y) const;
   std::size_t             caret_index(point p) const;
   break_enum              line_break(std::size_t index) const;
   break_enum              word_break(std::size_t index) const;
};
```

== Expressions

=== Notation

`r`         :: Object of type `text_run`.
`fd`        :: Object of type `font_descr`.
`s8`        :: Object of type `std::string_view`, UTF-8 text.
`s32`       :: Object of type `std::u32string_view`, UTF-32 text.
`w`         :: Floating point value for the line width.
`j`         :: `bool` value, whether to justify.
`glf`       :: Object of type `text_run::get_line_info`.
`fi`        :: Object of type `text_run::flow_info`.
`li`        :: Object of type `text_run::line_info`.
`cnv`       :: Object of type `canvas`.
`p`         :: Object of type `point`.
`x`, `y`    :: Floating point values for the coordinates of a point.
`c`         :: Object of type `color`.
`i`         :: `std::size_t` value, a code point index into `r.text()`.

=== Type Definitions

[cols="1,1,1"]
|===
| Expression                  | Semantics                         | Type

| `text_run::line_info`       | Get the type that places one
                                line, with the members `offset`
                                and `width`.                      | `struct`
| `text_run::flow_info`       | Get the type of the flow
                                parameters, with the members
                                `justify`, `line_height` and
                                `last_line_height`.               | `struct`
| `text_run::break_enum`      | Get the break type, an
                                enumeration of
                                `text_run::indeterminate`,
                                `text_run::must_break`,
                                `text_run::allow_break` and
                                `text_run::no_break`.             | `enum`
| `text_run::get_line_info`   | Get the type of the function
                                that places each line.            | `std::function<text_run::line_info(float)>`
|===

=== Constructors

[cols="1,1"]
|===
| Expression                  | Semantics

| `text_run(fd, s8)`          | Construct a `text_run` from `s8` (UTF-8
                                text, converted to UTF-32) in the font
                                `fd`. The run has no lines until it is
                                flowed.
| `text_run(fd, s32)`         | Construct a `text_run` from `s32` (UTF-32
                                text) in the font `fd`. The run has no
                                lines until it is flowed.
| `text_run(std::move(r))`    | Move construct from `text_run r`, leaving
                                `r` holding nothing.
|===

NOTE: C++ brace initialization may also be used.

A `text_run` can be neither copied nor assigned, not even by move.

WARNING: A moved from `text_run` holds nothing. Calling any member on it
other than the destructor is undefined behaviour.

=== Access

[cols="1,1,1"]
|===
| Expression              | Semantics                          | Return Type

| `li.offset`             | Access the x position where the
                            line starts, from the run's
                            origin.                            | `float`
| `li.width`              | Access the width the line may
                            take.                              | `float`
| `fi.justify`            | Access whether to justify.         | `bool`
| `fi.line_height`        | Access the distance between one
                            baseline and the next.             | `float`
| `fi.last_line_height`   | Access the distance between the
                            last two baselines.                | `float`
| `text_run::npos`        | Access `std::size_t(-1)`, what
                            `caret_index` returns for a point
                            below the last line.               | `std::size_t`
|===

=== Accessors

[cols="1,1,1"]
|===
| Expression              | Semantics                          | Return Type

| `r.text()`              | Get the text, as UTF-32. The view
                            is valid until the text is next
                            replaced.                          | `std::u32string_view`
| `r.num_lines()`         | Get the number of lines the last
                            flow produced, 0 before the first.
                            A text that ends in a hard break
                            has an empty last line.            | `std::size_t`
| `r.caret_point(i)`      | Get the caret position before code
                            point `i`: the left edge of its
                            glyph, on its line's baseline. An
                            `i` at or past the end gives the
                            end of the last line. `{0, 0}`
                            before the first flow.             | `point`
| `r.caret_index(p)`      | Get the index of the caret
                            position nearest `p`, or
                            `text_run::npos` if `p` is below
                            the last line's baseline. 0 before
                            the first flow.                    | `std::size_t`
| `r.caret_index(x, y)`   | Get the index of the caret
                            position nearest the point at `x`,
                            `y`, as `r.caret_index(p)`.        | `std::size_t`
| `r.line_break(i)`       | Get whether a line may break after
                            code point `i`, by the Unicode line
                            breaking rules (UAX #14).          | `text_run::break_enum`
| `r.word_break(i)`       | Get whether a word boundary
                            follows code point `i`, by the
                            Unicode word boundary rules
                            (UAX #29).                         | `text_run::break_enum`
|===

`caret_index` picks the line first, and it is the first line whose baseline
is at or below `p.y`. A `p.y` anywhere from just below the baseline of line
_k_ - 1 down to the baseline of line _k_ therefore selects line _k_, and a
point in the descenders of line _k_ selects line _k_ + 1. Within the line,
an `x` at or before its start gives its first index, and an `x` at or past
its end gives the index just past its last glyph: the space that ended it,
or the next line's first character. On the last line that is
`r.text().size()`. Between the two, `x` rounds to the nearest glyph
boundary.

NOTE: Where several code points share one glyph, as in the "fi" ligature,
the caret positions inside it depend on the backend.

The break queries return one of these values:

`text_run::must_break`     :: A break is required after `i`, which is a
                              hard line break such as `'\n'`.
`text_run::allow_break`    :: A break is allowed after `i`.
`text_run::no_break`       :: No break is allowed after `i`.
`text_run::indeterminate`  :: `i` is out of range, or, for `line_break`,
                              the last code point of a text that does not
                              end in a hard break.

`word_break` never reports `must_break`, and it reports `allow_break` for
the last code point.

=== Mutators

[cols="1,1,1"]
|===
| Expression      | Semantics                              | Return Type

| `r.text(s8)`    | Set the text to `s8`, converted from
                    UTF-8, and discard the lines: the run
                    has none until it is flowed again.     | `void`
| `r.text(s32)`   | Set the text to `s32` (UTF-32), and
                    discard the lines.                     | `void`
|===

=== Operation

[cols="1,1,1"]
|===
| Expression              | Semantics                          | Return Type

| `r.flow(w [, j])`       | Break the text into lines no wider
                            than `w`, each starting at x 0 and
                            spaced by the font's
                            `line_height()`, and justify them
                            if `j` is `true`. Default:
                            `j=false`.                         | `void`
| `r.flow(glf, fi)`       | Break the text into lines, calling
                            `glf` for where each line starts
                            and how wide it may be.            | `void`
| `r.draw(cnv, p [, c])`  | Draw the lines in the colour `c`,
                            with the run's origin at `p`.
                            Default: `c=colors::black`.        | `void`
| `r.draw(cnv, x, y
    [, c])`               | Draw the lines in the colour `c`,
                            with the run's origin at `x`, `y`.
                            Default: `c=colors::black`.        | `void`
|===

`flow(glf, fi)` calls `glf(y)` for each line, with `y` the baseline of that
line measured from the first line's baseline, and lays the line out at the
returned `li.offset` in at most `li.width`. Varying the two with `y` flows
text around a shape, or indents the first line. Lines are `fi.line_height`
apart, except that the last line's baseline is moved down by
`fi.last_line_height - fi.line_height`.

A justified line has its spaces widened so that it fills its width
exactly. The last line is left ragged, as is any line that ends in a hard
break and any line whose natural width is less than 90% of its width.
Quartz 2D and Skia also leave a line of exactly 90% ragged.

=== Example

Draw a justified paragraph with its first line indented, and a caret where
the mouse position `mp` falls in it.

```c++
#include <artist/text_run.hpp>
#include <artist/canvas.hpp>    // For canvas
#include <string_view>
...
using namespace cycfi::artist;
extern canvas cnv;              // the canvas to draw on
std::string_view text;          // the paragraph's text, UTF-8
point mp;                       // the mouse position
...
   auto fd = font_descr{"Open Sans", 20};
   auto fm = font{fd}.metrics();
   auto lh = font{fd}.line_height();

   auto para = text_run{fd, text};                                   <1>
   para.flow(                                                        <2>
      [](float y)
      {
         return y == 0
            ? text_run::line_info{30, 310}
            : text_run::line_info{0, 340};
      }
    , {true, lh, lh}
   );

   auto origin = point{60, 80};
   para.draw(cnv, origin);                                           <3>

   auto i = para.caret_index(mp.x - origin.x, mp.y - origin.y);      <4>
   if (i != text_run::npos)
   {
      auto cp = para.caret_point(i);                                 <5>
      cnv.stroke_style(colors::navy);
      cnv.move_to(origin.x + cp.x, origin.y + cp.y - fm.ascent);
      cnv.line_to(origin.x + cp.x, origin.y + cp.y + fm.descent);
      cnv.stroke();
   }
```

<1> Construct a run over the UTF-8 text in a 20 point Open Sans.
<2> Flow it justified, at the font's line height, with the first line
    indented by 30 and every line ending at x 340.
<3> Draw the run with its origin, the first line's baseline, at `origin`.
<4> Find the caret index nearest the mouse, in the run's own coordinates.
<5> Get the caret's baseline position, and stroke a caret from the
    ascent above it to the descent below.

Its output is the figure in the <<Overview>>.
