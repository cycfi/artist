= States

== Overview

The canvas draws with whatever styles, transform and clip are in effect at
the moment of the call. Those settings form one bundle, the drawing state,
and the canvas keeps a stack of them. `cnv.new_state()` pushes a copy of
the bundle and pops it again at the end of the enclosing scope. Everything
set in between is undone in one step.

This is how drawing code stays composable. A function that translates the
origin, narrows the clip and picks a font has changed the canvas for
everything drawn after it, and a clip in particular can only ever be
narrowed, never widened. Saving first and restoring at the end is the only
way to hand the canvas back as it was found.

`cnv.new_state()` is the whole interface. It returns an object that pushes
the state on construction and pops it when it goes out of scope, including
when an exception carries you out of the block. There is no way to push or
pop on its own.

The bundle holds the xref:canvas/styles.adoc[fill and stroke styles],
whether a colour or a gradient, the line width, cap, join and miter limit,
the shadow, the composite operation, the
xref:foundation/font.adoc[font] and the text alignment, the
xref:canvas/current_path.adoc#_fill_rule[fill rule], the
xref:canvas/transforms.adoc[current transform], and the clip.

It does not hold the xref:canvas/current_path.adoc[current path]. A shape
half built before a save is still half built after the restore, and one
built inside a scope is still there when the scope ends. Nor does it hold
the pixels: a restore is not an undo, and ink laid down inside a scope
stays where it landed.

NOTE: The bundle is the W3C canvas API's drawing state, which likewise
excludes the current default path and the bitmap, and a `new_state` scope
is its `save` and `restore` pair. Artist does not expose those two
separately.

== Design Rationale

The push and the pop are paired by the language: the object `new_state`
returns pops in its destructor, so the two halves cannot drift apart as the
code between them grows. The underlying `save` and `restore` are private,
and `canvas::state` is their only caller. The W3C API exposes the two
separately and leaves an unmatched `restore` as a silent no-op; a scope
makes that mistake unwritable.

== Include

```c++
#include <artist/canvas.hpp>
```

== Declaration

```c++
class canvas
{
public:

   class state
   {
   public:

               state(canvas& cnv);
               state(state&& rhs) noexcept;
               ~state();

      state&   operator=(state&& rhs) noexcept;
   };

   state       new_state();
};
```

== Expressions

The state members of xref:canvas.adoc[`canvas`] allow these expressions.

=== Notation

`cnv`             :: Object of type `canvas`.
`s`, `a`, `b`     :: Objects of type `canvas::state`.

=== Constructors and Assignment

[cols="1,1"]
|===
| Expression                       | Semantics

| `canvas::state(cnv)`             | Construct a `canvas::state` that pushes
                                     a copy of the drawing state of `cnv`.
| `canvas::state(std::move(s))`    | Move construct from `s`, taking over
                                     its save.
| `a = std::move(b)`               | Move assign `b` to `a`, taking over its
                                     save.
|===

NOTE: C++ brace initialization may also be used.

`canvas::state` is non-copyable: two objects popping one save would
unbalance the stack. A move hands the save over, and the moved-from object
holds nothing and pops nothing. The object is a token for one entry on the
stack and holds no copy of the state itself.

WARNING: Move assignment does not restore first. `a = std::move(b)`
overwrites whatever save `a` was holding without popping it, so that entry
stays on the stack for the rest of the drawing. Assign only over a `state`
that has already been moved from.

=== Operation

[cols="1,1,1"]
|===
| Expression          | Semantics                      | Return Type

| `cnv.new_state()`   | Push a copy of the drawing
                        state and return a
                        `canvas::state` that pops it
                        when destroyed.                | `canvas::state`
|===

Hold the result in a named local. A temporary is destroyed at the end of
the full expression, so `cnv.new_state();` on its own pushes and pops the
state and protects nothing.

image::canvas/state_stack.png[alt="Five swatches painted by the same statement, their colours following a nested pair of scopes", width=560px, align=center, title="One statement, five results: the fill style follows the stack.", link={imagesdir}/canvas/state_stack.png]

Every swatch above is painted by the same `fill_round_rect` call. Only the
depth of the stack differs, and with it the fill style the call reads. What
goes on comes back off in reverse, so the fourth swatch is the second one's
colour and the fifth is the first's.

A push and a pop have to balance, so the block's shape and the stack's
depth are the same thing.

```c++
#include <artist/canvas.hpp>
...
using namespace cycfi::artist;
extern canvas cnv;              // the canvas to draw on
path p;                         // the shape to clip to
point offset;                   // where to move the origin
...
   {
      auto st = cnv.new_state();
      cnv.clip(p);
      cnv.translate(offset);
      // draw
   }  // the clip and the transform are undone here
```

=== Example

Draw a label inside a panel, rotated and clipped to it, and leave the
canvas as it was found.

```c++
#include <artist/canvas.hpp>
...
using namespace cycfi::artist;
extern canvas cnv;              // the canvas to draw on
...
   auto panel = rect{20, 20, 260, 120};

   cnv.fill_style(rgba(21, 101, 192, 255));
   cnv.fill_round_rect(panel, 8);

   {
      auto st = cnv.new_state();                            <1>
      cnv.add_round_rect(panel, 8);
      cnv.clip();                                           <2>
      cnv.translate(panel.left + 20, panel.bottom - 26);
      cnv.rotate(-0.35);
      cnv.font(font_descr{"Open Sans", 34});
      cnv.fill_style(colors::white);
      cnv.fill_text("Artist Artist Artist", 0, 0);
   }

   // The clip, the transform, the font and the fill style are all back:
   // this lands outside the panel, unclipped and unrotated.
   cnv.fill_style(rgba(26, 26, 26, 255));
   cnv.fill_rect(280, 60, 40, 40);                          <3>
```

<1> Save the drawing state for the label.
<2> Clip to the panel. The label is longer than the panel and runs off its
    corner, where the clip cuts it.
<3> Fill a square after the scope ends. It is dark, square to the axes and
    outside the panel: none of the four settings had to be put back by
    hand.
