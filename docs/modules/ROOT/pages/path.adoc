= Path

== Overview

The `path` is a mathematical description of shapes: lines, rectangles,
cubic and quadratic curves, circles and arcs. Each shape is built from
primitives that describe how the path is formed, and the finished object
can be handed to the `canvas` to fill or stroke.

Build a `path` once and draw it many times. That is cheaper than rebuilding
the geometry on every draw, and graphics backends, GPU ones especially, are
optimized for immutable paths created outside the draw function.

TIP: To build geometry into the canvas directly, without an object to keep,
see xref:canvas/current_path.adoc[Current Path]. The two offer the same
primitives; the difference is whether the geometry outlives the draw.

== Include

```c++
#include <artist/path.hpp>
```

== Declaration

```c++
class path
{
public:

   enum fill_rule_enum
   {
      fill_winding,
      fill_odd_even
   };

                     path();
                     ~path();

                     path(rect const& r);
                     path(rect const& r, float radius);
                     path(circle const& c);
                     path(std::string_view svg_def);
                     path(path const& rhs);
                     path(path&& rhs);

   path&             operator=(path const& rhs);
   path&             operator=(path&& rhs);

   bool              operator==(path const& rhs) const;
   bool              operator!=(path const& rhs) const;
   bool              is_empty() const;
   bool              includes(point p) const;
   bool              includes(float x, float y) const;
   rect              bounds() const;

   void              close();

   void              add_rect(rect const& r);
   void              add_round_rect(rect const& r, float radius);
   void              add_circle(circle const& c);

   void              add_rect(float x, float y, float width, float height);
   void              add_round_rect(
                        float x
                      , float y
                      , float width
                      , float height
                      , float radius
                     );
   void              add_circle(float cx, float cy, float radius);

   void              move_to(point p);
   void              line_to(point p);
   void              arc_to(point p1, point p2, float radius);
   void              arc(
                        point p
                      , float radius
                      , float start_angle
                      , float end_angle
                      , bool ccw = false
                     );

   void              quadratic_curve_to(point cp, point end);
   void              bezier_curve_to(point cp1, point cp2, point end);

   void              move_to(float x, float y);
   void              line_to(float x, float y);
   void              arc_to(
                        float x1
                      , float y1
                      , float x2
                      , float y2
                      , float radius
                     );
   void              arc(
                        float x
                      , float y
                      , float radius
                      , float start_angle
                      , float end_angle
                      , bool ccw = false
                     );

   void              quadratic_curve_to(float cpx, float cpy, float x, float y);
   void              bezier_curve_to(
                        float cp1x
                      , float cp1y
                      , float cp2x
                      , float cp2y
                      , float x
                      , float y
                     );

   void              fill_rule(fill_rule_enum rule);
   fill_rule_enum    fill_rule() const;

   path_impl*        impl();
   path_impl const*  impl() const;
};
```

== Expressions

=== Notation

`p`, `a`, `b`                :: Objects of type `path`.
`r`                          :: Object of type `rect`.
`c`                          :: Object of type `circle`.
`pt`                         :: Object of type `point`.
`pt1`, `pt2`                 :: Objects of type `point`, the tangent
                                points of an arc.
`cp`, `cp1`, `cp2`           :: Objects of type `point`, the control points
                                of a curve.
`end`                        :: Object of type `point`, the end point of a
                                curve.
`x`, `y`                     :: Floating point values for the coordinates
                                of a point.
`w`, `h`                     :: Floating point values for the width and
                                height.
`cx`, `cy`                   :: Floating point values for the centre of a
                                circle.
`radius`                     :: Floating point value for a radius.
`x1`, `y1`, `x2`, `y2`       :: Floating point values for the tangent
                                points of an arc.
`cpx`, `cpy`                 :: Floating point values for the control point
                                of a quadratic curve.
`cp1x`, `cp1y`, `cp2x`, `cp2y` :: Floating point values for the control
                                points of a cubic curve.
`start_angle`, `end_angle`   :: Floating point values for angles in
                                radians.
`ccw`                        :: `bool` value for the sweep direction.
`svg_def`                    :: Object of type `std::string_view`.
`fr`                         :: Value of type `path::fill_rule_enum`.

=== Type Definitions

[cols="1,1,1"]
|===
| Expression              | Semantics                               | Type

| `path::fill_rule_enum`  | Get the fill rule type, an enumeration
                            of `path::fill_winding` and
                            `path::fill_odd_even`.                  | `enum`
|===

=== Constructors and Assignment

[cols="1,1"]
|===
| Expression              | Semantics

| `path()`                | Construct an empty `path`.
| `path(r)`               | Construct a `path` holding the rectangle `r`.
| `path(r, radius)`       | Construct a `path` holding the rectangle `r`
                            with its corners rounded to `radius`.
| `path(c)`               | Construct a `path` holding the circle `c`.
| `path(svg_def)`         | Construct a `path` from `svg_def` (the `d`
                            attribute of an
                            https://www.w3.org/TR/SVG11/paths.html#PathElement[SVG
                            path element]).
| `path(p)`               | Copy construct from `path p`.
| `path(std::move(p))`    | Move construct from `path p`.
| `a = b`                 | Assign `b` to `a`.
| `a = std::move(b)`      | Move assign `b` to `a`.
|===

NOTE: C++ brace initialization may also be used.

The `svg_def` parser accepts the commands `M`, `L`, `H`, `V`, `C`, `S`,
`Q`, `T`, `A` and `Z`, each in its absolute (uppercase) and relative
(lowercase) form.

WARNING: The `svg_def` constructor throws `std::runtime_error` if it
meets a command it does not recognize. Wrap it in a `try` block when the
string comes from anywhere but a literal in your own source.

=== Accessors

[cols="1,1,1"]
|===
| Expression           | Semantics                          | Return Type

| `p.is_empty()`       | Test whether `p` holds no
                         geometry.                          | `bool`
| `p.includes(pt)`     | Test whether `pt` lies inside `p`,
                         by the fill rule of `p`.           | `bool`
| `p.includes(x, y)`   | Test whether the point at `x`, `y`
                         lies inside `p`, by the fill rule
                         of `p`.                            | `bool`
| `p.bounds()`         | Get the smallest rectangle that
                         encloses `p`.                      | `rect`
| `p.fill_rule()`      | Get the fill rule.                 | `path::fill_rule_enum`
| `p.impl()`           | Get the underlying backend object:
                         a `CGPath` on Quartz-2D, an
                         `SkPathBuilder` on Skia, a
                         `cairo_artist_path_t` on Cairo, a
                         `d2d::path_impl` on Direct2D, a
                         `recording::path_impl` on the
                         recording backend. On a `const`
                         path it returns
                         `path_impl const*`.                | `path_impl*`
|===

WARNING: `impl` is an escape hatch for backend-specific work. Code that
uses it is not portable across backends.

=== Mutators

[cols="1,1,1"]
|===
| Expression           | Semantics                          | Return Type

| `p.fill_rule(fr)`    | Set the fill rule to `fr`.         | `void`
|===

The fill rule decides which regions of a self-intersecting path count as
inside. A path's fill rule governs `includes` and `canvas::clip(p)`.
Filling uses the canvas's own fill rule, set with `cnv.fill_rule(fr)`
(see xref:canvas/current_path.adoc[Current Path]).

=== Operation

[cols="1,1,1"]
|===
| Expression                    | Semantics                    | Return Type

| `p.add_rect(r)`               | Add the rectangle `r` as a
                                  closed shape.               | `void`
| `p.add_rect(x, y, w, h)`      | Add the rectangle at `x`,
                                  `y` (top left corner) of
                                  size `w` by `h` as a closed
                                  shape.                      | `void`
| `p.add_round_rect(r, radius)` | Add `r` with its corners
                                  rounded to `radius` as a
                                  closed shape.               | `void`
| `p.add_round_rect(x, y, w, h,
    radius)`                    | Add the rectangle at `x`,
                                  `y` (top left corner) of
                                  size `w` by `h`, with its
                                  corners rounded to `radius`,
                                  as a closed shape.          | `void`
| `p.add_circle(c)`             | Add the circle `c` as a
                                  closed shape.               | `void`
| `p.add_circle(cx, cy,
    radius)`                    | Add the circle centred on
                                  `cx`, `cy` with the given
                                  `radius` as a closed
                                  shape.                      | `void`
| `p.move_to(pt)`               | Move the current point to
                                  `pt` without drawing.       | `void`
| `p.move_to(x, y)`             | Move the current point to
                                  `x`, `y` without drawing.   | `void`
| `p.line_to(pt)`               | Add a straight line from the
                                  current point to `pt`.      | `void`
| `p.line_to(x, y)`             | Add a straight line from the
                                  current point to `x`, `y`.  | `void`
| `p.arc_to(pt1, pt2, radius)`  | Add an arc of the given
                                  `radius` between the
                                  tangents `pt1` and `pt2`.   | `void`
| `p.arc_to(x1, y1, x2, y2,
    radius)`                    | Add an arc of the given
                                  `radius` between the
                                  tangents `x1`, `y1` and
                                  `x2`, `y2`.                 | `void`
| `p.arc(pt, radius,
    start_angle, end_angle
    [, ccw])`                   | Add an arc centred on `pt`
                                  running from `start_angle`
                                  to `end_angle`. Default:
                                  `ccw=false`.                | `void`
| `p.arc(x, y, radius,
    start_angle, end_angle
    [, ccw])`                   | Add an arc centred on `x`,
                                  `y` running from
                                  `start_angle` to
                                  `end_angle`. Default:
                                  `ccw=false`.                | `void`
| `p.quadratic_curve_to(cp,
    end)`                       | Add a quadratic curve to
                                  `end` with control point
                                  `cp`.                       | `void`
| `p.quadratic_curve_to(cpx,
    cpy, x, y)`                 | Add a quadratic curve to
                                  `x`, `y` with control point
                                  `cpx`, `cpy`.               | `void`
| `p.bezier_curve_to(cp1, cp2,
    end)`                       | Add a cubic curve to `end`
                                  with control points `cp1`
                                  and `cp2`.                  | `void`
| `p.bezier_curve_to(cp1x,
    cp1y, cp2x, cp2y, x, y)`    | Add a cubic curve to `x`,
                                  `y` with control points
                                  `cp1x`, `cp1y` and `cp2x`,
                                  `cp2y`.                     | `void`
| `p.close()`                   | Close the current shape,
                                  joining its last point to
                                  its first.                  | `void`
|===

NOTE: `add_round_rect` clamps `radius` to the range
`0 .. min(w, h) / 2`, so an oversized radius gives the fully rounded
shape: a stadium, or a circle on a square.

The lines, arcs and curves extend the current shape from the current
point. `move_to` sets that point without drawing.

image::canvas/arc.svg[alt="arc parameters", width=280px, align=center, title="The centre, radius, and the two angles taken by arc.", link={imagesdir}/canvas/arc.svg]

image::canvas/bezier.svg[alt="curve control points", width=480px, align=center, title="Control and end points of the cubic and quadratic curves. The curve starts at the current point.", link={imagesdir}/canvas/bezier.svg]

NOTE: The Cairo and Skia backends clamp a negative arc `radius` to zero;
Quartz-2D, Direct2D and the recording backend pass it on as given.

NOTE: `ccw` defaults to `false`, which sweeps in the direction of
increasing angle. Because Artist's y axis grows downward, that appears
*clockwise* on screen. Pass `true` to reverse it.

=== Example

Build an arrow once and fill it at three positions.

```c++
#include <artist/path.hpp>
#include <artist/canvas.hpp>    // For canvas
...
using namespace cycfi::artist;
extern canvas cnv;              // the canvas to draw on
...
   // Built once, outside the draw function
   auto arrow = path{"M 0 0 L 40 20 L 0 40 L 10 20 Z"};      <1>

   // ... in the draw function
   cnv.fill_style(colors::navy_blue);
   for (int i = 0; i != 3; ++i)
   {
      auto s = cnv.new_state();
      cnv.translate(40.0f + i * 70, 30);
      cnv.add_path(arrow);                                    <2>
      cnv.fill();
   }
```

<1> Construct the arrow from an SVG path string. The string is parsed
    here, once, and not on every fill.
<2> Add the arrow to the current path. The `path` holds the geometry in
    its own coordinates, so the transform in effect at this call places
    it.
