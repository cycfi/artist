= Canvas

The canvas API is a derivative of and in line with the spirit the HTML5
canvas API, but using a slightly different syntax and naming convention
following standard c++ style (e.g. using lower-case and underscores as word
separators instead of camelCase).

The canvas API is built on top of xref:foundation.adoc[Foundation classes] such as
points and rectangles and some more drawable classes included in the page,
such as paths and images. The `path` encapsulates compound (multiple contour)
geometric paths consisting of straight line segments, quadratic curves, and
cubic curves.

== path

The `path` is the basic building block for a lot of drawing tasks that
involve the `canvas`. The path is a mathematical description of shapes, that
include lines, rectangles, cubic and quadratic curves, circles, arcs, etc.
Each shape in the path is constructed using a set of primitives that
represent instructions on how the path is formed.

For efficiency, it is advisable to construct a `path` once and draw it
multiple times. Graphics backends, especially those that involve the GPU, are
optimized for immutable paths that are created outside the UI draw function.

[source,c++]
----
class path
{
public:
                     path();
                     ~path();

                     path(rect const& r);
                     path(rect const& r, float radius);
                     path(circle const& c);
                     path(std::string_view svg_def);
                     path(path const& rhs);
                     path(path&& rhs);

   path&             operator=(path const& rhs);
   path&             operator=(path&& rhs);

   bool              operator==(path const& rhs) const;
   bool              operator!=(path const& rhs) const;
   bool              is_empty() const;
   bool              includes(point p) const;
   bool              includes(float x, float y) const;
   rect              bounds() const;

   void              close();

   void              add_rect(rect const& r);
   void              add_round_rect(rect const& r, float radius);
   void              add_circle(circle const& c);

   void              add_rect(float x, float y, float width, float height);
   void              add_round_rect(
                        float x, float y,
                        float width, float height,
                        float radius
                     );
   void              add_circle(float cx, float cy, float radius);

   void              move_to(point p);
   void              line_to(point p);
   void              arc_to(point p1, point p2, float radius);
   void              arc(
                        point p, float radius,
                        float start_angle, float end_angle,
                        bool ccw = false
                     );

   void              quadratic_curve_to(point cp, point end);
   void              bezier_curve_to(point cp1, point cp2, point end);

   void              move_to(float x, float y);
   void              line_to(float x, float y);
   void              arc_to(
                        float x1, float y1,
                        float x2, float y2,
                        float radius
                     );
   void              arc(
                        float x, float y, float radius,
                        float start_angle, float end_angle,
                        bool ccw = false
                     );

   void              quadratic_curve_to(float cpx, float cpy, float x, float y);
   void              bezier_curve_to(
                        float cp1x, float cp1y,
                        float cp2x, float cp2y,
                        float x, float y
                     );

   enum fill_rule_enum
   {
      fill_winding,
      fill_odd_even
   };

   void              fill_rule(fill_rule_enum rule);

   path_impl*        impl();
   path_impl const*  impl() const;
};
----

=== Expressions

[source,c++]
----
// Default constructor [1].
path{}

// Constructors [2].
path{ r }
path{ r, radius }
path{ c }
path{ svg_def }

// Copy constructor. [3]
path{ p }

// Assignment [4]
p = p2

// Equality [5]
p == p2

// Non-equality [6]
p != p2

// Check for empty path [7]
p.empty()

// Check for inclusion [8]
p.includes(pt)
p.includes(x, y)

// Get the path bounds [9]
p.bounds()

// Close path [10]
p.close()

// Add rectangle [11]
p.add_rect(r)
p.add_rect(x, y, width height)

// Add rounded rectangle [12]
p.add_round_rect(r, radius)
p.add_round_rect(x, y, width height, radius)

// Add circle [13]
p.add_circle(c)
p.add_circle(cx, cy, radius)

// Move current point [14]
p.move_to(pt)
p.move_to(x, y)

// Add an arc [15]
p.arc_to(pt1, pt2, radius)
p.arc_to(x1, y1, x2, y2, radius)

// Add an arc [16]
p.arc(pt, radius, start_angle, end_angle, ccw)
p.arc(pt, radius, start_angle, end_angle)
p.arc(x, y, radius, start_angle, end_angle, ccw)
p.arc(x, y, radius, start_angle, end_angle)

// Add a quadratic Bézier curve [17]
p.quadratic_curve_to(cp, end)
p.quadratic_curve_to(cpx, cpy, x, y)

// Add a cubic Bézier curve [18]
p.bezier_curve_to(cp1, cp2, end)
p.bezier_curve_to(cp1x, cp1y, cp2x, cp2y, x, y)

// Set the fill-rule [19]
p.fill_rule(fr)

----

=== Notation

[cols="1,3"]
|===
| `r` | Instance of `rect`.
| `pt`, `pt1`, `pt2` | Instance of `point`.
| `cp`, `cp1`, `cp2`, `end` | Instance of `point`.
| `x`, `y`, `width`, `height` | Scalar values.
| `radius`, `x1`, `y1`, `x2`, `y2` | Scalar values.
| `cpx`, `cpy` | Scalar values.
| `start_angle`, `end_angle` | Scalar values.
| `ccw` | A Boolean value.
| `c` | Instance of `circle`.
| `svg_def` | Instance of `std::string_view`.
| `p`, `p2` | Instance of `path`
| `fr` | Instance of `path::fill_rule_enum`
|===

=== Semantics
. Default construct a `path`.
. Construct a `path`:
.. A rectangle from a `rect`, `r`.
.. A rounded-rectangle from a `rect`, `r`, and `radius`.
.. A circle from a `circle`, `c`.
.. A complex path from a string view that conforms to the syntax of an
   https://www.w3.org/TR/SVG11/paths.html#PathElement[SVG path element].
. Copy construct a `path `, `p`.
. Assign `p2`, to `p`.
. Returns `true` if a `p2`, is equal to `p`.
. Returns `true` if `p2`, is not equal to a `p`.
. Returns `true` if `p` is empty.
. Returns `true` if point `pt` (or `x, y`) is inside `p`.
. Get the smallest rectangle that encapsulates the path, `p`.
. Close the current shape.
. Add rectangle, `r` (or `x, y, width height`), to the current path.
. Add rounded rectangle, `r, radius` (or `x, y, width, height, radius``) to
   the current path.
. Add circle, `c` (or `cx, cy, radius`) to the current path.
. Move the current point to `pt` (or `x, y`).
. Add an arc, to the current path, between two tangents `pt1` and `pt2` (or
   `x1, y1, x2, y2`) with the given `radius`.
. Add an arc, to the current path, given a center point, `pt` (or `x, y`),
   `start_angle` (in radians) and an `end_angle` and a `bool` flag, `ccw`,
   that specifies whether counterclockwise (flag is `false`) or clockwise
   (flag is 'true`). The default is `false` (clockwise).
. Add a quadratic Bézier curve to the current path using the specified
   control point, `cp` (or `cpx, cpy`) and ending point`end` (or `x, y`).
   The starting point for the curve is the current point.
. Add a cubic Bézier curve to the current path using the specified control
   points `cp1` and `cp2` (or `cp1x, cp1y` and `cp2x, cp2y`) and ending
   point`end` (or `x, y`). The starting point for the curve is the current
   point.
. Set the path's fill rule to `fr` (which can be `path::fill_winding` or
   `path::fill_odd_even`).

== canvas

The `canvas` is the surface you draw on. You do not construct one: the host
window creates a canvas for its drawing area and hands it to you for the
duration of the draw call.

Drawing follows the pattern of the HTML5 canvas. You set the styles you
want, build a path, then fill or stroke it. The styles are state held by
the canvas rather than arguments to each call, so a fill color set once
applies to every fill that follows until you set another.

[,c++]
----
cnv.fill_style(colors::navy_blue);
cnv.add_round_rect(bounds, 5);
cnv.fill();
----

The sections below catalogue the canvas interface. Throughout, `cnv` is an
instance of `canvas`.

== Validity

Tests whether the canvas wraps a real drawing surface, and reaches the
backend handle underneath.

=== Notation

`cnv`:: Instance of `canvas`

=== Expressions

[,c++]
----
// variant 1
bool(cnv)

// variant 2
!cnv

// variant 3
cnv.impl()
----

=== Semantics

. Returns `true` if the canvas wraps a real drawing surface. A canvas
handed to you by the host is always valid for the duration of the draw
call; the check exists for code that may run before a surface is ready.
. The negation of the above.
. Returns the backend handle: `SkCanvas*` for Skia, `cairo_t*` for Cairo,
`canvas_impl*` for Quartz2D. Reach for this only when you need a facility
of the backend that Artist does not expose.

'''

'''

== rotate

=== Expression

[,c++]

----

. Rotation is about the origin, not the centre of what you are drawing.
Translate first to rotate about some other point.

'''

== scale

`p`:: Instance of `point`
`xy`, `x`, `y`:: `float`

=== Expressions

[,c++]

cnv.scale(p)

'''

Converts a point between the coordinates you draw in (user space) and the

=== Notation

`p`:: Instance of `point`
`x`, `y`:: `float`

=== Expressions

[,c++]
----
// variant 1
cnv.device_to_user(p)

// variant 2
cnv.user_to_device(p)

=== Semantics

. Returns the `point` in user space corresponding to a device space

'''

== transform

Gets or replaces the current transform outright.

=== Notation

`mat`:: Instance of `affine_transform`
`a`, `b`, `c`, `d`, `tx`, `ty`:: `double`

=== Expressions

[,c++]
----
// variant 1
cnv.transform()

// variant 2
cnv.transform(mat)

// variant 3
cnv.transform(a, b, c, d, tx, ty)
----

=== Semantics

. Returns the current transform as an `affine_transform`.
. Replaces the current transform with `mat`.
. Replaces the current transform with the six values of a transformation
matrix.
. Unlike `translate`, `rotate`, `scale` and `skew`, which compose, setting
the transform replaces whatever is in effect.

'''

== begin_path / close_path

Starts a new path, and closes the current shape within it.

=== Expressions

[,c++]
----
// variant 1
cnv.begin_path()

// variant 2
cnv.close_path()
----

=== Semantics

. Discards the current path and starts a new one.
. Closes the current shape by drawing a straight line back to where it
began. A path may hold several closed shapes.

'''

== fill / stroke

Paints the current path, filled or outlined.

=== Expressions

[,c++]
----
// variant 1
cnv.fill()
cnv.stroke()

// variant 2
cnv.fill_preserve()
cnv.stroke_preserve()
----

=== Semantics

. Fills the current path with the current fill style, or strokes it with
the current stroke style. The path is consumed: the canvas begins a new one
afterwards.
. The same, but the path is left in place so it can be painted again. This
is how a shape is given both a fill and an outline.

[,c++]
----
cnv.fill_preserve();   // fill, keeping the path
cnv.stroke();          // then outline the same path
----

'''

== move_to / line_to

Moves the current point, and draws a straight line to it.

=== Notation

`p`:: Instance of `point`
`x`, `y`:: `float`

=== Expressions

[,c++]
----
// variant 1
cnv.move_to(p)
cnv.move_to(x, y)

// variant 2
cnv.line_to(p)
cnv.line_to(x, y)
----

=== Semantics

. Moves the current point to `p` (or `x, y`) without drawing.
. Adds a straight line from the current point to `p` (or `x, y`), which

'''

== arc

image::/canvas/arc.svg[alt="arc", width=260px, role=center]

Adds an arc of a circle, given its centre.

=== Notation

`p`:: Instance of `point`, the centre
`x`, `y`, `radius`:: `float`
`start_angle`, `end_angle`:: `float`, angles in radians
`ccw`:: `bool`

=== Expressions

[,c++]
----
// variant 1
cnv.arc(p, radius, start_angle, end_angle, ccw)
cnv.arc(p, radius, start_angle, end_angle)

// variant 2
cnv.arc(x, y, radius, start_angle, end_angle, ccw)
cnv.arc(x, y, radius, start_angle, end_angle)
----

=== Semantics

. Adds an arc centred on `p` (or `x, y`) with the given `radius`, running
from `start_angle` to `end_angle`.
. `ccw` selects the direction and defaults to `false`, clockwise.
. Angles are in radians.

'''

== arc_to

Adds an arc of a circle, given two tangents.

=== Notation

`p1`, `p2`:: Instance of `point`
`x1`, `y1`, `x2`, `y2`, `radius`:: `float`

=== Expressions

[,c++]
----
// variant 1
cnv.arc_to(p1, p2, radius)

// variant 2
cnv.arc_to(x1, y1, x2, y2, radius)
----

=== Semantics

. Adds an arc of the given `radius` tangent to both the line from the
current point to `p1` and the line from `p1` to `p2`.
. A straight line is added from the current point to where the arc begins,
if they differ.
. This is the call that rounds a corner: `p1` is the corner, and the arc
replaces it.

'''

== quadratic_curve_to / bezier_curve_to

image::/canvas/bezier.svg[alt="bezier", width=460px, role=center]

Adds a Bézier curve from the current point.

=== Notation

`cp`, `cp1`, `cp2`, `end`:: Instance of `point`
`cpx`, `cpy`, `cp1x`, `cp1y`, `cp2x`, `cp2y`, `x`, `y`:: `float`

=== Expressions

[,c++]
----
// variant 1
cnv.quadratic_curve_to(cp, end)
cnv.quadratic_curve_to(cpx, cpy, x, y)

// variant 2
cnv.bezier_curve_to(cp1, cp2, end)
cnv.bezier_curve_to(cp1x, cp1y, cp2x, cp2y, x, y)
----

=== Semantics

. Adds a quadratic Bézier curve to `end`, shaped by the single control
point `cp`.
. Adds a cubic Bézier curve to `end`, shaped by the two control points
`cp1` and `cp2`.
. Both start at the current point, which the curve leaves in the direction
of the first control point. `end` becomes the new current point.

'''

== add_rect / add_round_rect / add_circle

Adds a whole shape to the current path.

=== Notation

`r`:: Instance of `rect`
`c`:: Instance of `circle`
`x`, `y`, `width`, `height`, `radius`, `cx`, `cy`:: `float`

=== Expressions

[,c++]
----
// variant 1
cnv.add_rect(r)
cnv.add_rect(x, y, width, height)

// variant 2
cnv.add_round_rect(r, radius)
cnv.add_round_rect(x, y, width, height, radius)

// variant 3
cnv.add_circle(c)
cnv.add_circle(cx, cy, radius)
----

=== Semantics

. Adds the rectangle `r` (or `x, y, width, height`).
. Adds the same rectangle with its corners rounded to `radius`.
. Adds the circle `c` (or centre `cx, cy` and `radius`).

NOTE: `round_rect` and `circle` remain for code written against the
Cairo-only canvas, but are deprecated. Use `add_round_rect` and
`add_circle`.

'''

== add_path

Adds an entire `path`, built separately, to the current path.

=== Notation

`p`:: Instance of `path`

=== Expression

[,c++]
----
cnv.add_path(p)
----

=== Semantics

. The geometry of `p` is added to the current path.
. Building a `path` once and adding it on each draw is cheaper than
rebuilding the geometry call by call, especially on GPU backends.

'''

== fill_rule

image::/canvas/fill_rule.svg[alt="fill_rule", width=480px, role=center]

Sets the rule that decides what counts as inside a self-intersecting path.

=== Notation

`rule`:: `path::fill_rule_enum`

=== Expression

[,c++]
----
cnv.fill_rule(rule)
----

=== Semantics

. `path::fill_winding` counts the direction of each crossing, so
overlapping regions of a single shape stay filled.
. `path::fill_odd_even` counts crossings alone, so every second region is
left empty.
. The default is `path::fill_winding`.

'''

== line_cap

== line_join / miter_limit

image::/canvas/line_join.svg[alt="line_join", width=480px, role=center]

Sets the shape drawn where two stroke segments meet.

=== Notation

`join`:: `canvas::join_enum`
`limit`:: `float`

=== Expressions

[,c++]
----
// variant 1
cnv.line_join(join)

// variant 2

----

=== Semantics

. `canvas::bevel_join` cuts the corner flat, `canvas::round_join` rounds

== composite_op

Sets how new drawing combines with what is already on the canvas.

=== Notation

`mode`:: `canvas::composite_op_enum`

=== Expressions

[,c++]
----
// variant 1
cnv.composite_op(mode)

// variant 2
cnv.global_composite_operation(mode)
----

=== Semantics

. Sets the compositing mode. Variant 2 is the same operation under its
HTML5 name.
. The Porter-Duff operators are `source_over` (the default),
`source_atop`, `source_in`, `source_out`, their four `destination_`
counterparts, `copy` and `xor_`.
. The blend modes are `lighter`, `darker`, `difference`, `exclusion`,
`multiply`, `screen`, `color_dodge`, `color_burn`, `soft_light`,
`hard_light`, `hue`, `saturation`, `color_op` and `luminosity`.

NOTE: `darker` is the one mode the backends do not agree on. Quartz2D
implements the W3C PlusDarker rule exactly; Skia and Cairo approximate it
with a per-channel minimum.

'''

== linear_gradient

A gradient that runs along a line. May be used anywhere a color may.

=== Notation

`start`, `end`:: Instance of `point`
`startx`, `starty`, `endx`, `endy`:: `float`
`cs`:: Instance of `canvas::color_stop`
`offset`:: `float`, from 0.0 at the start to 1.0 at the end
`c`:: Instance of `color`

=== Expressions

[,c++]
----
// variant 1
canvas::linear_gradient{start, end}

// variant 2
canvas::linear_gradient{startx, starty, endx, endy}

// variant 3
gr.add_color_stop(cs)
gr.add_color_stop(offset, c)
----

=== Semantics

. Constructs a gradient running from `start` to `end`.
. The same, with the two points given as four scalars.
. Adds a color stop: `offset` is the position along the gradient and `c` is
the color there. A `color_stop` is the pair as a struct.

[,c++]
----
auto gr = canvas::linear_gradient{{0, 0}, {0, 100}};
gr.add_color_stop({0.0, colors::black});
gr.add_color_stop({1.0, colors::white});
cnv.fill_style(gr);
----

'''

== radial_gradient

A gradient that runs between two circles.

=== Notation

`c1`, `c2`:: Instance of `point`, the two centres
`c1r`, `c2r`:: `float`, the two radii
`c1x`, `c1y`, `c2x`, `c2y`:: `float`

=== Expressions

[,c++]
----
// variant 1
canvas::radial_gradient{c1, c1r, c2, c2r}

// variant 2
canvas::radial_gradient{c1x, c1y, c1r, c2x, c2y, c2r}
----

=== Semantics

. Constructs a gradient running from the circle centred at `c1` with
radius `c1r` to the circle centred at `c2` with radius `c2r`.
. The same, with the centres given as scalars.
. Give both circles the same centre for the usual radial fill; offset them
for a cone-like effect.
. Color stops are added as for `linear_gradient`.

'''

== fill_text / stroke_text

Draws text at a point, filled or outlined.

`utf8`:: Instance of `std::string_view`, holding UTF-8 text
`p`:: Instance of `point`
`x`, `y`:: `float`

image::/canvas/draw.svg[alt="draw", width=460px, role=center]

Draws an `image` onto the canvas.

== new_state / save / restore

Saves and restores the canvas state: its styles, transform and clip, taken
together.

=== Notation

`cnv`:: Instance of `canvas`

=== Expressions

[,c++]
----
// variant 1
cnv.new_state()

// variant 2
cnv.save()
cnv.restore()
----

=== Semantics

. Saves the state and returns a `canvas::state` that restores it when
destroyed, including when an exception carries you out of the block. It may
be moved but not copied.
. Saves and restores the state by hand. Every `save` needs a matching
`restore`.
. Variant 1 is preferable for that reason.

[,c++]
----
{
   auto state = cnv.new_state();
   cnv.clip(p);
   cnv.translate(offset);
   // draw
}  // the clip and the transform are undone here
----
