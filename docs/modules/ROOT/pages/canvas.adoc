= Canvas

The canvas API is a derivative of and in line with the spirit of the HTML5
canvas API, but using a slightly different syntax and naming convention
following standard {cpp} style (e.g. using lower-case and underscores as
word separators instead of camelCase).

The canvas API is built on top of xref:foundation.adoc[Foundation classes]
such as points and rectangles, and on drawable classes such as
xref:path.adoc[Path] and xref:foundation/image.adoc[Image].

== Overview

The `canvas` is the surface you draw on. Usually you do not construct one:
the host window creates a canvas for its drawing area and hands it to you
for the duration of the draw call. To draw into an image instead, you
construct a canvas yourself on an `offscreen_image`'s context; see
xref:foundation/image.adoc[Image].

Drawing follows the pattern of the HTML5 canvas. You set the styles you
want, build a path, then fill or stroke it. The styles are state held by
the canvas rather than arguments to each call, so a fill color set once
applies to every fill that follows until you set another.

[,c++]
----
cnv.fill_style(colors::navy_blue);
cnv.add_round_rect(bounds, 5);
cnv.fill();
----

The pages in this section catalogue the canvas interface.

* xref:canvas/transforms.adoc[Transforms] map user space onto the surface.
* xref:canvas/current_path.adoc[Current Path] builds geometry into the
  canvas itself, then paints it. For geometry kept as an object, see
  xref:path.adoc[Path].
* xref:canvas/styles.adoc[Styles] decide how fills and strokes render.
* xref:canvas/gradients.adoc[Gradients] fill and stroke with a ramp of
  color.
* xref:canvas/rectangles.adoc[Rectangles] build and paint in one step.
* xref:canvas/text.adoc[Text] draws and measures strings.
* xref:canvas/images.adoc[Drawing Images] paints an image onto the canvas.
* xref:canvas/states.adoc[States] save and restore the canvas.

Throughout, `cnv` is an instance of `canvas`.

== Validity

Tests whether the canvas wraps a real drawing surface, and reaches the
backend handle underneath.

=== Notation

`cnv`:: Instance of `canvas`

=== Expressions

[,c++]
----
// variant 1
bool(cnv)

// variant 2
!cnv

// variant 3
cnv.impl()
----

=== Semantics

. Returns `true` if the canvas wraps a real drawing surface. A canvas
handed to you by the host is always valid for the duration of the draw
call; the check exists for code that may run before a surface is ready.
. The negation of the above.
. Returns the backend handle: `SkCanvas*` for Skia, `cairo_t*` for Cairo,
`canvas_impl*` for Quartz2D. Reach for this only when you need a facility
of the backend that Artist does not expose.
