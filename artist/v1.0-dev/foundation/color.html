Color

Overview

A color is a red, green, blue and alpha quadruple of float. The components are nominally 0.0 to 1.0, but nothing in the type clamps them, so a computed color can carry values outside that range until a backend consumes it. Alpha is straight, not premultiplied.

The whole type is constexpr, members included, so palettes can be built at compile time. It is a small trivially copyable struct; pass it by value.

A default constructed color is {0, 0, 0, 0}, which is transparent black, not opaque black. Use colors::black when opaque black is what you want.

The library ships a large set of named colors and a neutral gray ramp in the cycfi::artist::colors namespace. See Predefined Colors.

Include

#include <artist/color.hpp>

Declaration

   struct color
   {
      constexpr         color() = default;
      constexpr         color(
                           float red, float green
                         , float blue, float alpha = 1.0f
                        );

      constexpr color   opacity(float alpha_) const;
      constexpr color   level(float amount) const;

      float red   = 0.0f;
      float green = 0.0f;
      float blue  = 0.0f;
      float alpha = 0.0f;
   };
   // Free functions
   constexpr bool    operator==(color const& a, color const& b);
   constexpr bool    operator!=(color const& a, color const& b);

   constexpr color   operator+(color const& a, color const& b);
   constexpr color   operator-(color const& a, color const& b);
   constexpr color   operator*(color const& a, float b);
   constexpr color   operator*(float a, color const& b);

   constexpr color   rgb(std::uint32_t rgb);
   constexpr color   rgba(std::uint32_t rgba);
   constexpr color   rgb(std::uint8_t r, std::uint8_t g, std::uint8_t b);
   constexpr color   rgba(
                        std::uint8_t r, std::uint8_t g
                      , std::uint8_t b, std::uint8_t a
                     );
   constexpr color   hsl(float h, float s, float l);

Expressions

Notation

c, c2

Objects of type color.

r, g, b, a

Floating point component values, nominally 0.0 to 1.0.

ur, ug, ub, ua

Objects of type std::uint8_t, 0 to 255.

u

Object of type std::uint32_t, typically a hex literal.

h

Floating point hue in degrees, 0 to 360.

s, l

Floating point saturation and lightness, 0.0 to 1.0.

amount, k

Floating point multipliers.

i

An integer index.

Constructors and Assignment

Expression Semantics

color{}

Default construct {0, 0, 0, 0}, transparent black.

color{r, g, b}

Construct from the three color components. Alpha takes its default of 1.0, fully opaque.

color{r, g, b, a}

Construct from all four components.

color(c)

Copy construct from c.

c = c2

Assign c2 to c.
color declares its own constructors, so it is not an aggregate and brace initialization calls a constructor rather than initializing members in order. That is why color{r, g, b} is opaque, picking up the default argument, while color{} is transparent, picking up the member initializers.

Comparison

Expression Semantics Return Type

c == c2

bool

c != c2

The negation of the above.

bool

The members are public and directly assignable. There are no accessors.

The red component.

float

c.green

The green component.

float

c.blue

The blue component.

float

c.alpha

The alpha component, 0.0 fully transparent and 1.0 fully opaque.

float

Derivation

Both are const and return a new color; c is not modified.

Expression Semantics Return Type

c.opacity(a)

A copy of c with the alpha replaced by a. The color components are untouched.

color

c.level(amount)

A copy of c with the three color components multiplied by amount. The alpha is untouched.

color
level does not clamp. An amount above 1 pushes components past 1.0, and they stay there until a backend clips them.

Arithmetic

Expression Semantics Return Type

c + c2

Sum the three color components. The alpha is c.alpha + c2.alpha * (1 - c.alpha), the usual source over rule.

color

c - c2

Difference of the three color components. The alpha uses the same source over formula as +, not a difference.

color

c * k

Multiply the three color components by k, leaving the alpha unchanged. Equivalent to c.level(k).

color

k * c

The same, with the operands reversed.

color
These are plain component arithmetic, not a compositing model. Nothing is clamped, so a sum can exceed 1.0 and a difference can go negative. The alpha of c - c2 combining rather than subtracting is what the implementation does today; do not rely on it.

Free Functions

Expression Semantics Return Type

rgb(u)

Unpack u as 0xRRGGBB and scale each byte by 1/255. The alpha is 1.0.

color

rgba(u)

Unpack u as 0xRRGGBBAA and scale each byte by 1/255.

color

rgb(ur, ug, ub)

As above, from three separate bytes. The alpha is 1.0.

color

rgba(ur, ug, ub, ua)

As above, from four separate bytes.

color

hsl(h, s, l)

Convert hue, saturation and lightness to red, green and blue. The alpha is 1.0.

color
hsl clamps h to 359.99 before converting, so hsl(360, s, l) is close to, but not exactly, hsl(0, s, l). Nothing wraps or clamps a negative hue, so keep h within 0 to 360.

Predefined Colors

The cycfi::artist::colors namespace holds 131 named colors and a 101 entry gray ramp, all of them constexpr. The usual way to reach them is to alias the namespace:

   namespace colors = cycfi::artist::colors;
Figure 1. The 131 named colors in cycfi::artist::colors, in declaration order.

The names follow the familiar X11 and CSS list, but the values do not all match the CSS definitions of the same name. green is rgb(0, 255, 0), which CSS calls lime; purple is rgb(160, 32, 240) rather than the CSS rgb(128, 0, 128); orange is rgb(255, 135, 0) rather than rgb(255, 165, 0). Read the value from the header when an exact match matters. Three pairs are the same color under two names: tan and burly_wood, salmon and dark_salmon, and navy and navy_blue.

The Gray Ramp

Figure 2. colors::gray is 101 neutrals from black to white, one per percent.
Expression Semantics Return Type

colors::gray

An array of 101 neutral colors from black to white, one per percent, so gray[i] is the neutral at i percent. Valid indices are 0 to 100.

color const[101]

colors::grey

A synonym for colors::gray.

color const*
The ramp has 101 entries, not 256. gray[128] and gray[255] are out of bounds.
grey is declared constexpr auto grey = gray;, so the array decays and grey is a pointer, not an array. Indexing works as expected, but grey cannot be used where an array is required, std::size for one.

Example

A panel fill and the brighter shade it takes when hovered, laid over a neutral backdrop at 60 percent opacity:

   namespace colors = cycfi::artist::colors;

   constexpr auto panel = colors::dark_slate_blue;
   constexpr auto hover = panel.level(1.2f);

   cnv.fill_style(colors::gray[20]);
   cnv.fill_rect(bounds);

   cnv.fill_style((hovered? hover : panel).opacity(0.6f));
   cnv.fill_rect(bounds);
