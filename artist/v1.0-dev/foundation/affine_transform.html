Affine Transform

Overview

The affine_transform is the matrix behind the canvas Transforms. It maps a point in the coordinates you draw in, called user space, to a point in the coordinates of the surface, called device space. It is what canvas::transform() returns and what canvas::transform(mat) takes.

Figure 1. The six stored members and the mapping they define. The third column is fixed and is not stored.

The a, b, c and d members carry the linear part, which is scale, rotation and skew. The tx and ty members carry the translation. A default constructed affine_transform is the identity.

The type is a plain aggregate of six double members, so it is cheap to copy and usable in constant expressions. Everything except rotate, skew, make_rotation and make_skew, which need std::sin, std::cos and std::tan, is constexpr.

Artist’s y axis grows downward, so a positive rotation, which takes the positive x axis toward the positive y axis, appears clockwise on screen.
See Foundation for an overview of the foundation classes.

Include

#include <artist/affine_transform.hpp>

Declaration

struct affine_transform
{
   constexpr bool                   is_identity() const;
   constexpr affine_transform       translate(double tx, double ty) const;
   constexpr affine_transform       scale(double sx, double sy) const;
   constexpr affine_transform       scale(double sc) const;
   inline affine_transform          rotate(double rad) const;
   inline affine_transform          skew(double sx, double sy) const;
   constexpr affine_transform       invert() const;

   constexpr point                  apply(point p) const;
   constexpr point                  apply(float x, float y) const;

                                    template <std::size_t N>
   constexpr void                   apply(point (&p)[N]) const;
   constexpr void                   apply(point p[], std::size_t n) const;

   double a    = 1.0;
   double b    = 0.0;
   double c    = 0.0;
   double d    = 1.0;
   double tx   = 0.0;
   double ty   = 0.0;
};

Constructors and Assignment

Expression Semantics

affine_transform()

Construct the identity transform, {1, 0, 0, 1, 0, 0}.

affine_transform{a, b, c, d, tx, ty}

Construct an affine_transform given the six members, in declaration order.

affine_transform(t)

Copy construct from affine_transform t.

t1 = t2

Assign t2 to t1.
affine_transform is an aggregate with no user declared constructors. The members may be given in part and the rest take their default values, so affine_transform{2.0} is a scale of 2 in x only.

If the determinant, a * d - c * b, is zero, t is not invertible and invert returns t unchanged. No error is reported, so check the determinant yourself if a degenerate transform is possible.
t.apply(pts) deduces the count from the array type of pts. The arithmetic is done in double and narrowed to the float members of point.

Comparison

The comparison of the six members is exact, so two transforms differing only by rounding are not equal.

Arithmetic

Expression Semantics Return Type

t1 * t2

Get the transform that applies t2 first and then t1, so that (t1 * t2).apply(p) equals t1.apply(t2.apply(p)).

affine_transform

The composing members are defined as t * make_translation(tx, ty) and so on, which means the new operation applies within the space t already establishes. This is the same rule the canvas calls follow: scaling by 2 and then translating by 10 moves by 20 device units. Composition is not commutative, so t1 * t2 and t2 * t1 differ in general.

Make a skew, {1, tan(kx), tan(ky), 1, 0, 0}: kx is the angle by which y shears with x, and ky the angle by which x shears with y.

affine_transform

Scale and rotation are about the origin, not the centre of what you are drawing. Translate first to work about some other point.

Example

Rotate a point by 45 degrees about the point {cx, cy}.

#include <artist/affine_transform.hpp>
...
using namespace cycfi::artist;
float cx, cy;                            // the point to rotate about
float x, y;                              // the point to map
...
   auto t = affine_identity
      .translate(cx, cy)                                 (1)
      .rotate(M_PI / 4)                                  (2)
      .translate(-cx, -cy)                               (3)
      ;

   auto p = t.apply(point{x, y});                        (4)
1 Start from the identity and translate by cx and cy, the last step applied to the point.
2 Rotate by 45 degrees.
3 Translate by -cx and -cy, the first step applied to the point, which brings {cx, cy} to the origin.
4 Map the point {x, y} through t.
