Path

Overview

The path is a mathematical description of shapes: lines, rectangles, cubic and quadratic curves, circles and arcs. Each shape is built from primitives that say how the path is formed, and the finished object can be handed to the canvas to fill or stroke.

Build a path once and draw it many times. That is cheaper than rebuilding the geometry on every draw, and graphics backends, GPU ones especially, are optimized for immutable paths created outside the draw function.

To build geometry into the canvas directly, without an object to keep, see Current Path. The two offer the same primitives; the difference is whether the geometry outlives the draw.

Constructors and Assignment

Expression Semantics

path()

Construct an empty path.

path(r)

Construct a rectangle from r.

path(r, radius)

Construct a rounded rectangle from r with corner radius.

path(c)

Construct a circle from c.

path(svg_def)

Construct from a string holding the d attribute of an SVG path element.

path(p)

Copy construct from p.

path(std::move(p))

Move construct from p.

p = p2

Assign p2 to p.

p = std::move(p2)

Move assign p2 to p.
C++ brace initialization may also be used.

The svg_def parser accepts the commands M, L, H, V, C, S, Q, T, A and Z, each in its absolute (uppercase) and relative (lowercase) form.

The svg_def constructor throws std::runtime_error if it meets a command it does not recognize. Wrap it in a try block when the string comes from anywhere but a literal in your own source.

p.close()

Close the current shape, joining its last point to its first.

void

Both arc overloads take ccw as a defaulted parameter, so it may be omitted. Angles are in radians and radius is clamped to be non-negative.

ccw defaults to false, which sweeps in the direction of increasing angle. Because Artist’s y axis grows downward, that appears clockwise on screen. Pass true to reverse it.

Fill Rule

The fill rule decides which regions of a self-intersecting path count as inside, and it governs both filling and includes.

Figure 3. The same star under the two fill rules.
Expression Semantics Return Type

p.fill_rule(fr)

Set the fill rule to fr, either path::fill_winding or path::fill_odd_even.

void

p.fill_rule()

The current fill rule.

path::fill_rule_enum
The getter is compiled only for the Quartz-2D backend. The setter is available on all three.

Backend Access

Expression Semantics Return Type

p.impl()

The underlying backend object: a CGPath on Quartz-2D, an SkPathBuilder on Skia, a cairo_artist_path_t on Cairo.

path_impl*
impl is an escape hatch for backend-specific work. Code that uses it is not portable across backends. There is a const overload returning path_impl const*.

Example

Building a shape once and drawing it many times:

   // Built once, outside the draw function
   auto arrow = path{"M 0 0 L 40 20 L 0 40 L 10 20 Z"};

   // ... in the draw function
   cnv.add_path(arrow);
   cnv.fill_style(colors::navy_blue);
   cnv.fill();
